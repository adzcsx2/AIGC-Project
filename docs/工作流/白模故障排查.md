# 白模故障排查

只读当前症状相关项；完整流程见 [白模制作与验收](白模制作与验收.md)。先保存问题版本和证据，再修改新版本。测量、视觉判断、模型效果分开记录。

| 症状 | 先查什么 | 修法与复查 |
|---|---|---|
| 画面平灰、主体消失 | 实际相机、渲染可见性、墙/柜体遮挡、主体明度 | 查几何和射线证据；必要门窗做真开口；再看送模版，不先反复改焦距 |
| 审片版清楚，送模版糊在一起 | 相邻物体的实际像素明度与轮廓 | 调整本片灰度分层并检查实际送模帧；不同材质名称不代表有明度差 |
| 检查通过但送模版失焦、模糊或近乎空白 | 相机景深开关的关键帧/NLA/驱动、运动模糊开关及实际渲染帧 | 新版仅在导出副本禁用相应开关通道并复查渲染求值；若模糊开关还控制焦距/几何而导致指纹变化，先在新工程副本解除该依赖再重检；不删除整组相机动画、不覆盖原工程 |
| 送模灰度被染色、亮度错误或出现源工程标注 | 场景/输出端颜色管理、曲线、白平衡、曝光/Gamma、use_stamp及其动画/驱动 | 新版按显示属性清单固定中性颜色和无标注输出，并在逐帧与渲染后核对；复查失败的图片不发布。使用新检查版本，不改源工程调色，不以几何指纹相同代替像素检查 |
| 同一个角色出现两次 | 同帧启用的角色组、旧姿态副本、集合可见性 | 按镜头切换实际渲染可见性；检查每帧，不只改审片静帧 |
| 朝向/左右关系错误 | 世界坐标、相机右向、鼻/脸/肩朝向 | 用实际投影确认；不套“所有相机正对墙”或固定转角公式 |
| 手与道具分离 | 手部求值后世界坐标、父子关系、握持左右手 | 道具绑定握持锚点，声明接触区间并逐帧量距离 |
| 圆柱离地、穿过树干或路径错误 | 占位体积、地面/树干表面、接触锚点与高度曲线 | 修简单几何的空间与接触；圆柱平移本身是路径代理，不为模拟自然步态增加精细四肢，不能称步态已通过 |
| 幼体生成成巨兽 | 代理世界尺寸、相对比例、透视、角色图和实际英文尺度条款 | 同时锁定引导与提示词的相对尺度；不能只写“小龙”或归咎模型，不自动重抽 |
| 起落像慢动作、顶点悬停、落地发飘 | 实际fps/PTS、位移与阶段秒数、速度曲线、顶点平台及持续升力依据；对照白模/原生/最终同一动作相位 | 按[速度与真实物理时间](白模制作与验收.md#速度与真实物理时间)先修时序和插值，不能只锁最高点或用补帧/全片加速补救；原速复核后再放行，不自动重抽 |
| 外框变高却无法判断体型是否变大 | 头冠/足底、尾翼计入范围、抬头/直立/腿姿、相机/透视及同姿态参照 | 分开体高、实体尺度与距地高度，先比落地同姿态/可比身体部位；像素候选保留误差，不能将展翼外框或足底高度当3D体积证明 |
| 要爬树却仅水平绕树 | 代理离树表面距离、垂直高度变化、遮挡和抓握描述 | 在简单代理上做真实贴树升降/绕行，英文写爪抓与身体推进；仅几厘米装饰起伏不能冒充剧情所需爬升 |
| 生成步态僵硬或出现柱体颜色 | 是否要求逐帧复制刚性代理，是否遗漏身份/颜色用途与自然动作 | 分开空间继承与模型补全，颜色只是标签；按根规则审计提示词，不返回复杂骨骼建模 |
| 上身攻击只拍到腿 | 发力、武器最大展开、接触和反馈的覆盖 | 在攻击前抬镜/拉开/切回；用完整动作预览检查，截图合格不能代替 |
| 包围框越界，但实看片似乎完整 | 检查主体范围、镜头是否本来就是近景、旋转几何的保守包围框 | 按真实构图目标选择关键身体部位与检查条件，并保存视觉依据；不为消除报错盲目放宽 |
| 场景检查说固定机位，画面在动 | 实际相机矩阵、镜头焦距/偏移和约束 | 在计划填写camera_motion；分别检查主体运动与摄影机运动 |
| 遮挡到处报警或明显漏报 | 是否把隐藏对象算入、是否跳过所有墙、目标是否选错 | 按实际渲染可见性和指定主体检测；有限射线只作定位，实看片确认 |
| 切点偏一帧 | 零起算帧索引与Blender从1起算的换算 | 切换发生在frame_start+start_frame；统一入含出不含，不在多份文档手填时间 |
| 检出过多/过少切点 | 解码、阈值、快速动作/闪光、相似构图 | 保留原阈值结果，显式重测新记录；一对一匹配，逐口动态复核 |
| 检查包不能复用 | 计划、工程、角色、创作依据或视频哈希改变 | 回到变化后的版本重新检查；不改旧记录伪装通过 |
| 灰方块、描边、文字被带入生成片 | 实际送模视频和参考图是否含这些信息 | 分离审片/送模版，检查图片；按授权另存干净参考，保留原图 |
| 生成片多出身体/龙头、局部没被替换 | 实际主体检测、全身轮廓、遮挡部位与完整映射 | 按真实模型能力排查；白模检查不能保证模型完整替换，不自动收费重抽 |
| 提示词校验通过但画面不对 | 校验是否只查关键词、是否真的比了场景/资产 | 查英文正文、实际输入和证据；不能继承上游中文词数/标题检查的通过结论 |
| 工程里看着已改，后台结果没变 | 修改是否保存、脚本/参数是否回写 | 全新进程加载实际文件或从固定代码重建；不只依赖is_dirty |
| 森林引导拒绝目录或旧版本 | 真实解析路径、最近project.yaml、布局/合成的全部输出是否占用 | 解除跨作品目录联接，选择未占用版本；两个阶段只使用独立重载的已保存工程，调用方内存修改须先另存 |
| 首帧无字但双版本导出被拒绝 | 后续帧的文字对象及hide_render动画 | 按报告帧号清理副本中的标注；不能仅隐藏首帧后绕过整段检查 |
| 对象视口不显示但渲染显示，工具拒绝 | 对象监视器/眼睛、集合与图层集合视口隐藏 | 在副本取消视口禁用，保留用途所需hide_render；隐藏父节点和约束目标同样可能造成求值差异 |
| 主体在相机XY范围内却不可见 | 实际clip_start/clip_end与主体深度 | 在副本修正裁切范围或主体位置；完整入画检查包括近远裁切面 |
| 工程哈希没变但位移/缓存结果变了 | 未打包图片、外部缓存、模拟与几何节点 | 图片先打包；无法可靠绑定/重播的缓存和节点转换为工程内几何/变换，当前工具会明确拒绝 |
| 固定机位检查发现缩放 | 感光尺寸、sensor_fit、透视/正交类型与实际投影 | 按摄影意图修正动画或声明moving，不只查location和lens |
| 导出视频被压窄或拉宽 | 工程像素比例和视频SAR/DAR | 使用新版工具显式编码SAR并核对显示画幅；保留旧输出另存版本 |
| 检查说主体入画，渲染却没有主体 | 当前视图层与启用渲染层、集合Exclude/Holdout/Indirect Only、对象Holdout/Shadow Catcher | 当前工具只支持当前层为唯一渲染层及普通可见性；在工程副本统一后重检，不只改测量层 |
| 旧白模入口拒绝作品或版本占用 | 最近project.yaml、配置与来源的真实归属、处理期间新出现的目标 | 嵌套作品不能混用；选择未占用版本，保留已发布诊断；不要删除其他任务产物绕过排他发布 |
| 多视频轨切点与播放器不一致 | 检查记录video_stream_index和播放器选择的视频轨 | 工具固定检测第一个视频流并使用同流PTS；需要其他轨时先明确另存所选轨 |

上游特定经验（长镜头约6秒、参考视频30秒、固定提示词顺序、最多6条硬约束）不作通用限制。按本次剧情、原片和真实接口决定，不为适配示例拆碎作品。
