### 2026-11-08纠正：MiniMax H3模型能力与AutoDL封装必须分开

MiniMax官方H3 V2接口支持在同一个`content`数组中组合中文文本、`reference_image`图片、
`reference_video`视频及可选参考音频。官方Ref2VA用途包括视频编辑、动作参考和续写。
因此不能根据下述AutoDL专用工作流的字段限制，推断“H3本身不支持白模视频加多张图片”。
官方入口为`POST /v2/video_generation`，模型`MiniMax-H3`；中国站当前文档使用
`https://api.minimax.cn`，国际站使用`https://api.minimax.io`，凭据须与对应服务匹配。

截至本次核对，官方允许最多9张参考图、3段参考视频；单段视频2–15秒、合计不超过15秒。
三张图分别提供人物、场景、互动角色，一段白模提供动作和镜头，符合该输入组合。
所有图片必须用`reference_image`，不混入`first_frame`或`last_frame`。
官方输出时长仍为整数4–15秒，不能声称自动原样保留7.133333秒；输入支持与复刻质量需要分开验收。

本项目目前接入的是AutoDL接口，尚未接入MiniMax官方V2；AutoDL Token不能当作MiniMax官方Key使用。
`minimax_h3_802`没有视频字段；`minimax_h3_zm_titi/titim`为带内置提示词的专用替换工作流，
不能直接视为官方通用Ref2VA入口。若用户要求白模驱动，实际请求必须包含白模视频；缺少兼容接口时不得
悄悄降级为图片加文字重新演绎，也不得因为名称包含H3就声称所有入口能力相同。

来源：[MiniMax官方中文V2参数](https://platform.minimax.cn/docs/api-reference/video-generation-v2-create)、
[国际站V2参数](https://platform.minimax.io/docs/api-reference/video-generation-v2-create)、
[官方Ref2VA说明](https://design.minimax.io/h3)。具体项目复核见`projects/扶柱滑倒/05-检查与验收/素材与成片检查/复审-版本02/平台能力审计.md`。

## 白模、深度和姿态的区别

- 白模预演：用三维简模表达空间、动作、摄影机路径和节奏，新制作优先本机Blender；旧scene.json引擎只承接指定流程。
- 白模外观转绘：让视频呈现无纹理白色人物的外观，通常是生成式编辑，不等于得到可编辑3D模型。
- 深度视频：每帧表达远近结构的估计，去色/灰度滤镜不具有这种含义。
- 姿态和遮罩：分别记录关节运动和重绘区域，仍需兼容的生成模型与输入契约。

核对过的官方候选：

- [Video Depth Anything](https://github.com/DepthAnything/Video-Depth-Anything)：视频深度估计，需其权重与推理依赖。
- [VACE](https://github.com/ali-vilab/VACE)：参考、视频转视频、遮罩编辑，需部署实际模型及预处理链路。
- [Wan Animate 预处理说明](https://github.com/Wan-Video/Wan2.2/blob/main/wan/modules/animate/preprocess/UserGuider.md)：
  animation 产出 face/pose，replacement 另有背景与遮罩；不代表所有任务都先转深度。

本次没有下载这些 GPU 模型，也没有把候选声明为可调用的 AutoDL 端点。
当前27个工作流没有独立 depth/pose/mask 控制参数，要闭合此路线需新的真实执行端。

## 白模技能边界

用户2026-11-09已指定本机Blender优先，新增两个入口见[接入记录](../工具与接口/blender-integration.md)。
其他工具生成的合格白模可直接作为视频参考，与用户选定人物图、场景图一起交现有替换流程；
无需先重建三维。只有要制作/修改可编辑白模时才用Blender。以下为保留的旧引擎说明。

huashu-seedance 主要面向 Seedance 的参考视频与提示词，已安装引擎可在工作目录运行：

```powershell
node E:/AutoDL/.agents/skills/huashu-seedance/engine/probe.mjs scene.json
node E:/AutoDL/.agents/skills/huashu-seedance/engine/build.mjs scene.json
node E:/AutoDL/.agents/skills/huashu-seedance/engine/make_prompt.mjs scene.json
```

渲视频另需 hyperframes@0.7.107 和浏览器运行时，照片叠网格需 opencv-python。
引擎不能从任意实拍视频自动得到人体关节和场景。Seedance 的 @白模1 语法不是 H3 的 API 参数。
简化白模也不一定被 H3 的主体检测识别，不能承诺随意接入即可换角。
索引中的 VideoClaw 有云端动作迁移，但要另一套平台与供应商凭据；已有 AutoDL 可完成该任务，
这次用原片拆解和白模引擎补充能力，没有部署第二套视频平台。
