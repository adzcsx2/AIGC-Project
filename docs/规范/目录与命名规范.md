# 目录与命名规范

共享资产采用 `projects/共享资产库/`，入口project.yaml明确标记asset_library，资产索引是专用目录而非生产materials。角色/场景/道具版本主档在01-文档，分类媒体在02-素材；作品的materials和角色YAML记录所用版本。本地只读主档快照在 `01-文档/角色/共享版本/`，它是冻结使用依据，不是第二份可编辑身份。具体路径基准、元数据职责、导入和版本规则见 [共享资产流程](../工作流/asset-library.md)。

人物档案新增 `01-文档/角色/<中文识别描述>.yaml`，一人一份，由project.yaml.characters索引。人物属性/声音选择/试听确认以人物YAML为准；materials继续登记素材技术状态、文案确认和镜头输入绑定。声音文件在 `02-素材/音频/角色声音/<人物描述>/`，候选被选中只更新引用、不复制。详见 [人物与声音流程](../工作流/character-voice.md)。

用户2026-11-10确认：作品归 `projects/<中文作品名>/`，公共程序归 `tools/`，公共知识归 `docs/`。不再建立根 assets、outputs、输入作为新作品入口。

| 作品内位置 | 存什么 |
|---|---|
| project.yaml | 短入口：当前版本、阶段、下一步、问题和文件指针 |
| materials.yaml | 资产状态、文案确认、镜头输入绑定；已有分集/版本清单保持独立 |
| 01-文档/需求与剧本、视觉设定、分镜与运镜、提示词、角色 | 创作正文；角色每人一份YAML；说明用中文，模型提示词用英文 |
| 02-素材/参考原片、人物、场景、道具、衔接图、音频 | 本片输入；音频按对白、配乐、环境声与音效细分 |
| 03-制作/制作计划、生成配置、三维工程、中间数据 | YAML、剪辑/混音配置、工程、时序数据 |
| 04-输出/原始片段、处理过程、成片 | 原始结果、派生文件、干净母版、水印发布版 |
| 05-检查与验收 | 审计、检查帧、短预览、全部接缝及声音审片证据 |
| 06-记录 | 用户确认、生成任务、素材来源、交付记录及目录索引 |
| 99-历史 | 旧版状态、弃用文档、迁移映射，不作新任务默认 |

按需创建子目录。分集/分支可在分类内保留原 `剧集/EP001/版本/`。中文语义素材名，保留真实扩展名；模型 ID、task_id、内部资产 ID 不翻译。原始 API 下载名可保留 task_id。

project.yaml 不复制剧本或资产 ready 状态。资产及绑定以 materials 为准，长正文以 Markdown 为准，详细验收以带哈希的记录为准。修改剪辑后配乐时间线、接缝和审片证据需重新核对。旧 `当前制作状态.json` 已归档，不再双写。

创作作品的当前风格由 `project.yaml.documents.style` 指向已有视觉设定，常规路径为 `01-文档/视觉设定/视觉设定.md`；materials的style项指向同一文件并登记技术状态，不再另建重复style.yaml。正文可引用共享风格规范、基准图与人物YAML，采用 [视觉设定模板](../../templates/short-drama/视觉设定.md) 补齐；各段提示词是带来源版本的派生结果。进行中的已提交版本保持原文件/哈希，新修订另存并在新制作采用时更新指针，细节见 [导演流程](../工作流/director-workflow.md)「项目风格与防漂移」。

有白模制作任务时，`whitebox_plan`指向 `03-制作/制作计划/白模计划.yaml`。计划只维护制作时间轴、工程与检查目标；`whitebox_evidence`可引用当前 `05-检查与验收/白模-版本NN/白模检查包.json`。人物、声音、创作正文与素材状态仍按各自唯一来源读取。公共工具不复制作品视频；审片版和送模版是用途不同的派生输出。

`materials_manifest` 与 `documents` 只指向已选制作分支；`production_selection` 记录选择依据及候选清单路径。清单按 documents/assets 结构识别，中文文件名也纳入；多候选不能按目录深度、名称或修改时间选当前版。没有明确选择时留空这两个指针并记录 unselected，不能把旧版当当前版。唯一清单可作为文档入口，但不代表文案确认或生成授权；已有明确选择不得被迁移重建覆盖。

`last_accepted_delivery` 独立指向最近有明确用户确认的交付文件、SHA-256及原始确认记录；登记前核对文件和哈希。待用户审片、技术通过、图片接受及音乐未通过均不能填为已确认交付。已确认成片不自动选择下一次制作分支，也不覆盖当前待处理问题；没有可核实记录则为 null。人物的 source_documents 保留建档来源，不随未选制作分支被清空，也不自动成为当前创作稿。

## 去重、历史和回滚

完整 SHA-256 相同才合并冗余副本；不同内容版本不删。帧序列或跨作品独立输入仍需路径时，可用 NTFS 硬链接保留逻辑条目。链接媒体视为只读，修改必须另存，禁止原地改写。网页审片直接读取原文件，不复制完整视频。

迁移前原始字节及清单在本机 `.autodl/reorganization/20261110/`，按哈希存一份。这是回滚备份，不是工作素材或第二套状态。确认迁移无误前保留。历史脚本集中在 `tools/视频工具/历史脚本/`，保留执行原文，只作追溯，不直接运行。

`tools/项目.py where <旧路径>` 查询迁移结果；兼容映射只用于恢复，新配置使用真实新路径。`tools/目录整理.py` 和 `tools/建立项目入口.py` 属于本次一次性迁移脚本，不重复执行覆盖状态。

## 公共目录

- docs/工作流：导演、分段、配乐、复刻；docs/工具与接口：接口和集成说明。
- docs/视觉规范：共享风格，引用原作品基准图，不复制素材。
- docs/维护记录：规则/技能审计；docs/验证记录：本机私有验证；docs/plan：工程规划。
- tools/视频工具：剪辑、抽帧、补帧、水印、审片、音乐。作品只保存参数和结果。
- src：API 客户端；tests：测试；templates：空模板；catalog：真实接口快照。
- .autodl：恢复索引、缓存和迁移备份，不新建作品成片目录。
