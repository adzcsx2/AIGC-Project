# 物体与角色尺寸约束：规则补充

用户要求：“物体的大小约束方式这点补充到规则里”。依据为本聊天横向绕树05使用的体量类比、可抱持参照和相对女孩身高描述；本次仅维护规则，不生成媒体、不改写既有任务或作品素材。

## 归属与变更

- AGENTS.md加入通用大小约束入口；详细方法唯一维护在导演流程「主体与物体的尺寸约束」，不把本片幼犬、五分之一或厘米数推广为所有作品默认。
- 规则区分实体大小、所在高度与画面占比，保留必要的精确数值；大小类比不改变身份，不把可抱/可握的参照偷换成当前剧情动作。
- 白模流程同步图/代理/英文正文的尺度一致性与摄影投影核对；修掉根规则“爬树必须升降”的旧冲突，按用户确认分别处理横向绕树、爬升、下降。
- visual-assets、video-retargeting、storyboard-camera、character-reference-board、cinematic-script-audit入口只增加对统一规则的简短引用；未改技能职责或UI元数据，不复制详细流程。电影级检查清单、生成前审计模板和视觉设定模板加入对应检查/依据字段。
- installed-skills.yaml仅更新上述入口的SKILL哈希及电影级检查清单引用哈希；保留其他登记、历史指纹、数量和并行改动。

## 验证

- skill-creator的quick_validate.py已验证5个直接修改的技能入口。首次遇本机默认GBK解码UTF-8文档失败，改用Python的-X utf8运行后全部通过；未改校验器或全局编码配置。
- 新增7处相对链接及中文锚点均可解析，受影响Markdown代码块闭合，登记YAML可解析且目标指纹与文件一致。
- git diff --check对受影响的已跟踪入口/登记无空白错误；已有CRLF/LF提示不作全量换行处理。结构校验不冒称模型尺寸效果已通过。

语义复核采用以下场景，不调用模型或收费接口：

| 场景 | 规则应产生的处理 |
|---|---|
| 小幼龙追逐，使用幼犬体量/双臂易抱/相对身高 | 类比只比大小，保留龙的结构；可抱不是此镜头抱持，横向绕树不强加升高。 |
| 用户给出精确6厘米的道具 | 保留精确数值，按实际镜头选择已有手/物体参照；不禁数字，也不强制新增比尺演员。 |
| 巨型生物 | 选择与场景建筑/人物相容的大小关系，不套幼犬或五分之一，不硬塞双臂抱住。 |
| 单角色身份板或面部近景 | 不靠头像/格子大小推断同场尺寸；无相关体量需求时不硬加参照、不重做合格图。 |
| 遮挡重现或镜头推近 | 维持实体大小，结合透视/姿势判断变化，不为精确屏幕比例逐帧缩放实体；实际比例未测不称通过。 |

结论：规则、直接受影响入口/模板和登记已同步；“类比一定比数字有效”没有被写成事实，白模与措辞同时变化的本次样本不作单变量因果证明。
