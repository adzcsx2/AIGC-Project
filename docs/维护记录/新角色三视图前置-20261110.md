# 新角色三视图前置与API身份绑定

用户本轮要求：以后出现新人物，包括动物，先生成三视图并将三视图交API，不能直接在场景图片中生成人物后仅将该图片交API。

根规则新增强制前置，详细流程唯一维护在 [人物流程](../工作流/character-voice.md#新角色三视图前置与api绑定)。沿用上一轮固定三视图，覆盖人类、动物、怪物及其他非人角色；无原图时从已确认设定直接生成板，已有同身份合格板复用。场景/镜头图继承板的身份，后续请求仍须实际绑定三视图文件，不能仅在prompt或materials中提到。

同步范围：根规则、README、导航/路由、导演流程、角色板入口/UI/版式/英文模板使用说明、visual-assets、short-drama-workflow、video-retargeting、autodl-aigc、电影级检查清单、角色与素材/镜头模板、生成前审计模板，以及受影响技能指纹。没有修改API客户端、schema或历史作品记录；本轮不生成媒体。

## 语义复核

| 情形 | 规则落地 |
|---|---|
| 新人物仅有文字设定 | 读取已确认设定与项目style直接制作三视图，不虚构原图、不先做场景人物。 |
| 新猫、鸟或幼龙，无对白 | 按真实结构制作相同三种视图，避免人形站姿/衣服；无对白不触发配声。 |
| 场景里已有临时生成的新角色 | 场景局部或裁切不能冒充三视图，不能仅凭场景图提交下游请求。 |
| 多角色生成 | 每个角色独立三视图，逐一核对人物ID、资产路径/哈希、真实输入槽位及容量。 |
| 首尾帧入口不支持额外身份板 | 在准备阶段解决兼容方案，不把三视图塞进场景端点字段，不静默忽略要求。 |
| 已有合格同身份三视图或旧任务恢复 | 前者核对后复用，后者按原task_id恢复；不倒改历史提交。 |
| 只写提示词或更新本规则 | 保持文字交付，不自动触发生成；已授权媒体制作中的新角色三视图无需另点名。 |

原路由中“只有单独要求参考板才生成”“单图不强制变参考板”已按本轮范围修正；场景/角色职责、身份输入真实性及授权边界复核一致。本次只改通用英文模板的使用说明，未交付或提交任何作品提示词；实用时仍需按具体角色改写、二次审计与实际图像验收。
