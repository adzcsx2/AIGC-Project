# 白模复刻与人物参考板技能审计

日期：2026-11-08。范围：保存版本08成片，沉淀已验证做法与失败教训，审计并补齐角色板生成流程。本轮不生成新视频或图片。

## 现有能力与处理决定

| 现有技能 | 已有能力 | 缺口与处理 |
|---|---|---|
| 用户级 `clay-video-retargeting` | 白模测量、素材职责、输入契约、转绘提示词 | 更新原技能：加入身体结构冲突诊断、白模副本改造、两次实看、完整案例及真实偏差 |
| 项目 `video-retargeting` | H3/Wan路线、素材绑定、API执行衔接 | 接入白模经验；移除“默认静音”导向，更新直接生成授权 |
| `s-grade-3d-prompts` | 角色身份板、正背俯仰板的一致性写法 | 有相似能力，但缺少用户要求的五视图、实际运动格及直接生成验收；保留审美方法，转新专项入口 |
| `short-drama-image-prompts` | 三视图等文字提示词，只写文本 | 不是直接生成与验收技能；添加新专项路由 |
| `short-drama-assets` | 角色与场景资产描述 | 不生成图片，不冒充角色板生产入口 |

新建 `.agents/skills/character-reference-board`：同一灰底板包含全身正背侧、脸部正侧，有运动用途时加入真实运动姿态；按用户明确生成请求用image_gen，实际逐格检查并定向修正。保留MJ明确选择；不调用即梦账号。

## 规则冲突处理

- 新角色板版式优先于旧的正背俯仰四格。俯仰按真实镜头需要补，已有合格双姿态板继续可用。
- 原片复刻保留原时长、路径和镜头，不套普通原创15秒/多机位模板。
- 角色板生成请求授权内置image_gen；一般图片仍按已有选择，技能安装本身不触发生成。
- 视频明确请求不再重复确认费用；一次请求一次当前方案提交，保留ID恢复，不自动付费重抽。
- 灰底角色板与环境分工；姿态板不代替时序控制。无腿蛇妖去腿，而有腿爬行角色/飞行机甲保留原肢体。

## 场景推演审计（静态规则核对，非新模型实测）

| 输入或错误 | 技能应作出的处理 |
|---|---|
| 原片双腿跑＋单尾蛇妖，要求向左爬出再冒脸 | 记录左侧路径和近景时序；保留原声；审查爬行图并改白模下身，不仅堆负面词 |
| 后续用户改方向 | 更新事件表、引导、prompt和绑定文件一起审计，拒绝沿用旧相反轨迹 |
| 柱子→法海，照片抠图锯齿 | 完整干净中性人形占位，角色图只锁身份；检查接触高度和遮挡 |
| 六格蛇妖图，某格尾巴分叉 | 逐格检查并修该结构；不能把全板总头数当单角色数量，也不把盘绕两段弧误判两尾 |
| 有腿机甲飞行 | 加飞行格、保留腿及既有推进器；引导检查离地和接地阴影，不能照搬蛇妖去腿 |
| 用户只发半身要求五视图 | 保守补全未见结构并说明；不声称恢复真实背面，不新增无依据配件 |
| 只有普通多图接口、没有ref_video | 不伪造参考视频输入，按真实能力选择路线 |
| 生成任务SUCCESS但尾尖未完全离开 | 媒体成功与动作验收分开，交代残留偏差，不记录为完美成功 |
| 用户仅要求总结技能 | 保存文档与当前视频，不启动收费新视频或额外图片 |
