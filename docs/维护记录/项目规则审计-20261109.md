## 规则走读

以下是有上下文的静态走读，不是模型生成、浏览器或API端到端测试。

| 场景 | 应有行为 | 走读结果 |
|---|---|---|
| 只要求写剧本 | 电影级基准先行，专业技能按缺口介入，交中文剧本，不启动媒体制作 | 与当前规则一致 |
| 只补一次攻击 | 先沿用创作基准，再由fight补动作，未确认的剧情不推进正式下游 | 与当前规则一致 |
| 原创动作图，没有源视频 | 使用已确认动作/分镜评估展开范围，明确尚无源片 | 已补齐 |
| 四段视频，最后一批图待接受 | 全部方案先总审计并展示结论，再让用户接受该批图；接受后各段一次提交 | 已消除第4/5步倒置 |
| 用户初始已明确要求生成 | 准备与总审计完成后按现有授权继续，不新增收费/预算确认；实质改稿仍需决定 | 与当前规则一致 |
| 只查task_id | 查询/等候/下载同一任务，不重编剧本或新POST | 与当前规则一致 |
| 只要求接缝优化 | 读取现有片段，逐口匹配与修剪，保留关键动作，音画同步并复查；不自动付费重抽 | 已消除漏检分支 |
| 白模换角色 | 保留原动作/运镜/原声，检查身体适配；源片不是白模时不能假造视频输入 | 与当前规则一致 |
| 最终视频交付或明确补到60fps | 先完成剪辑/接缝及音轨，再自动补到60fps并实查；已达目标核验复用，用户明确例外优先 | 用户已确认；相关默认与专项行为一致 |
| 只审计规则 | 文档与元数据检查，保留原任务/素材/凭据，不执行收费测试 | 本次遵守 |
