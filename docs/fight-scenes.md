# 打斗戏工作流

最新阶段规则见 [导演规则](director-workflow.md)：细节不足先交中文补全文案让用户确认，再继续分镜/英文提示词/制作。逐段运镜与整体变化由storyboard-camera审计。

用户可以只描述一个打斗想法。默认由 [fight-scene-design](../.agents/skills/fight-scene-design/SKILL.md)
补齐动作、运镜、打击反馈、特效、声音和连续性，按已选身份、身体结构、场景和目标模型交付提示词。
不要求用户自己列出专业摄影术语或完整招式。

普通打斗默认动作麻利、迅速、有力量：短促起手、明确发力、接触有反冲、回收立即接招；
删去无效蓄势、慢速空挥和双方同时停顿。具体规则已写入AGENTS与打斗导演技能，成片按实际动作验收。
连续性必须落实到位移路径、距离闭合与相邻动作接口；追击没到不能切成贴身打斗。
多种技能按威胁、应对、破局与终局串成短故事，详见 [空间与因果连续性](../.agents/skills/fight-scene-design/references/空间与因果连续性.md)。
每次攻击/技能都须有可见的短促起手与发力，动作驱动特效释放；角色静止而地刺等自行出现属于未达标。
用户明确要求30秒时可按 [两段续接规则](../.agents/skills/fight-scene-design/references/两段续接.md)
执行15秒＋尾帧续接15秒，第二段更激烈；不以参考图输入冒充严格首帧接口。

## 从想法到交付

1. 查看已选图、作品文档和已有成片，提取固定事实；沿用已明确的画风、身份和场景。
2. 先补全中文动作稿并取得用户确认，再继续正式分镜与提示词。设计完整攻防交换：支撑发力、攻击路线、目标点、格挡或闪避、受力与恢复、下一招。
3. 给动作安排有目的的机位和切点；空间方向连续，接触面可读，机震与真实撞击同步。
4. 为不同材料和能力设计有源的效果、声音与遗留，受伤有吃痛且伤势不因切镜消失。
5. 按当前模型整理可复制提示词、参考图顺序及控制范围、参数和素材清单。写入前二次审计。
6. 用户只要求提示词时交付文本；已要求生成时，在素材/参数校验通过后直接执行当前任务，
   不重复确认费用。未指定预算省略预算参数；失败或效果不足不自动再次付费提交。

普通已确认15秒原创连续打斗一次连续生成，可含多个内部机位；不强制至少六切，不自动拆成多个3—5秒短片。
原视频复刻交给 `video-retargeting`，保留源片长度、镜头顺序和原声，不重编动作。
图片遵守项目MJ手动与已授权人物参考板例外；已有合格多视图板不为凑模板重做。

## 科幻与身体兵器

用户允许时从现有甲壳、骨板、爪、根须或机械结构衍生兵器，明确连接点、数量、左右、展开方式和能源。
效果分为实体受力、材料破坏、环境传递、声画同步；先保证去掉粒子仍看懂谁打谁。
详见 [科幻打击适配](../.agents/skills/fight-scene-design/references/科幻打击与身体兵器.md)。
写实怪物按非人身体运动；风格模式名称不代表模型能保证非人结构。

## API与素材

用户2026-11-09最新指定：白模视频用 `minimax_h3_zm_titim`，非白模用 `minimax_h3_zm_u24`。
它是新的默认生成选择；下方804/805说明保留为历史接口比较，不继续作为默认路由。
当前已验证u24支持最长15秒、多图与可选参考音频，没有 `style_preset` 或严格 `first_frame` 输入；
使用其自身分辨率枚举（例如 `768p横`），提交前仍读取实时规则。不得因默认接口不支持某需求而静默换接口。

工作流按最新详情与实际 `input_rules` 核对，不把营销名称、技能示例或视觉形容词当接口能力。
2026-11-08已核对：`minimax_h3_804` 是H3九图15s多模式版；`minimax_h3_805` 增加最多三路参考音频。
两者均有 `style_preset: 武打模式-真人-武戏+真实质感`，内部映射模式4，API应传枚举文字。
805详情要求无声音驱动需求时选804，不向805传空音频；后续运行仍核对实时规则。
分辨率从枚举选择；“4K画质”不能改变输出分辨率。不虚构未暴露的质量/速度开关。

所有生产YAML带 `materials_manifest` 和 `shot_id`，通过项目 `validate/run` 或 `VideoProject.generate`。
素材必须实看并满足当前需求；多视图板绑定身份，不是多个人物或分镜格轮播。
双怪物已有板用于身份参考，新增身体兵器在提示词写明，避免“完全不变”与局部衍生互相冲突。

## 验收

生成后检查时长、尺寸、完整解码及声音，再看连续动作和接触前后帧，记录停顿、受力、武器、特效、伤势与场景连续性。
原始脚本只能审查其文本模板；SUCCESS只是服务完成，不能代替速度、打击感或动作验收。
不达标写清时段与问题；只做已授权下一步，不用自动拆分或付费重抽掩盖失败。
