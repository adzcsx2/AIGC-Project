# 人物三视图与运动参考板

用户给一张图并要求多角度时，实际看图、选择版式、调用允许的图像工具生成、检查再交付同一张板；只要求提示词时才停在文本。不是把原图镜像/重复裁切当侧面和背面，也不声称能从一张图恢复不可见的真实背面。

## 输出约定

基础内容是**全身正面、全身背面、全身严格侧面、面部正面、面部严格侧面**，都在同一张中性灰底图中，保持同一人物和同一套造型。侧面注明朝向；默认展示角色左侧、鼻尖朝画面左。全身与脸部的侧面采用同一侧，不能左右镜像伤痕和不对称配件。

用户已说明或视频表明角色要运动时，**在同一张板里加入该角色实际运动方式的姿态格**。默认一个最能消除歧义的姿态：走路角色用迈步承重，蛇妖用侧前方低姿蛇行，飞行机甲用悬空飞行；不能全部套“站直、脚落地”。需要起飞到巡航两种形态时才加第二格。蛇妖的“直立”表示上身抬起、蛇腹/尾承重，不允许为了三视图给她生成人腿。

用户只要静态三视图且没有运动用途时不擅自新增运动设计；已明确爬行或飞行时不重复问。已有合格参考板可复用，不为满足新模板重做所有老素材。

## 先审计参考

1. 看原图全幅和脸部，记录身份锚点：脸型五官、发型、颜色、头饰、耳饰、服装层次、不对称痕迹、身体比例和肢体/尾翼数量。不能只靠文件名猜。
2. 区分原图可见事实与新补设计。只有半身时，全身下部和背面按已见材质/结构保守延续；不无故添武器、发饰、尾巴或推进器。缺少决定性设定才问；一般遮挡细节合理补全并在交付说明。
3. 有动作视频先看代表帧与关键动作，明确支撑面、推进方式、身体朝向和运动状态，不能把原片人类腿部动作强加给无腿角色。
4. 原图背景只用于理解原图，不自动带入身份板。默认灰底、柔和均匀照明、清晰轮廓；场景母图另存。场景动作关键帧是另一用途，不能把此板当成固定首帧。

## 版式与提示词

按 [版式和运动格](references/版式与运动格.md) 分配画面。常用16:9：上部正背侧全身三格，下部两个脸部格＋一个较宽运动格。总共六个视图但不强制等面积；长蛇尾或展翼需要较宽空间，不能把尾尖、鞋或翼尖裁掉。人物占比按每格可用区域实际检查，面部格要足够清楚。

按 [中文提示词写法](references/中文提示词写法.md) 写本角色的具体正文；使用 `s-grade-3d-prompts` 时只继承适用材质/一致性方法，不改变原图画风，不机械套原角色、九头身或俯仰四格模板。全身侧面必须是真90度；正背不互相复制。近景允许脸部裁切，全身格则保留完整结构；不要写全图所有格都“完整全身”。

交付或调用前再次审计：五种视图齐全、运动格正确、左右与不对称细节、同一身份、每格身体结构、无静态模板冲突、场景槽位留空、画幅和工具参数有效。模板说明和占位符不直接发送给模型。

## 生成与工具选择

- 在本项目，用户通过本技能明确要求“帮我生成参考板/多角度”时，按最新授权使用内置 `image_gen`，优先于旧的仅MJ提示词流程；本轮只是建技能时不生成媒体。先读可用的 `imagegen` 技能。
- 本地输入先用 `view_image` 看图，然后通过 `referenced_image_paths` 传入；只有对话图片且无本地路径时按工具规则使用最小的 `num_last_images_to_include`，二者不能同时传。灰底是不透明背景，`transparent_background: false`。优先一次生成完整板，避免各角度独立抽样造成换脸。
- 用户明确选择Midjourney则只交中文正文、挂图顺序与实际参数，遵守 `docs/midjourney-local.md`；不自动操控网页提交。普通Imagine与Editor分开处理，MJ参数不塞给内置image_gen。
- 即梦工作台只作为用户想要的功能形态说明，不据此声称已接通即梦或替用户调用未配置服务。

## 实际验收与定向修正

查看全板，再逐格放大检查，不能只看缩略图或因为提示词写了“一条尾巴”就通过：

- 身份：五官、发型、发饰、服装、色彩和材质一致；背面的补设计可与正侧结构相接。
- 视角：正、背、严格侧真正不同；脸正侧清楚，侧面不是四分之三；每个身体格只有一个完整角色，近景格是同一个人的脸。
- 数量：逐格沿身体从根到末端检查。蛇妖每个身体格一条连续尾，无分叉、第二蛇头或人腿脚；跨格重复同一条尾的视角正常。蛇尾盘绕的两段可见弧不自动当成两尾，要追踪连接；存在无法辨别的交叉就修正成可读结构。
- 运动：爬行格上身放低、腰腹连续、腹鳞接地、唯一尾尖可追踪，不能是站姿横移。飞行格结构与推进方向清楚、确有离地空间；人形机甲保留原有双腿，不照搬蛇妖“无腿”。
- 排版：没有跨格连接的尾/翅，头手衣摆和结构末端不出框，不用背景、动效、运动残影遮错；脸部细节可读，不同格不混成多个角色同场表演。

有缺陷时先定位具体格与错误，保留已合格部分及原身份图，使用image_gen进行局部/整体定向重生成并复查；**默认最多两次定向修正**，用户另有明确迭代范围则遵从。仍不合格时交代失败项及最小缺口，不无限循环或把待修图标ready。这是角色板修正范围，不自动授权新增收费视频重抽。

合格图保存到 `assets/作品名/人物-角色名-三视图面部与运动参考板-版本01.png` 等实际中文路径，保留原图及版本。交付整板、实际保存路径、简短通过项/补设计说明；不把模板路径当成现存素材。

## 进入视频

角色板只控制一个角色的身份、结构及允许姿态，不复制灰底、格线和排列，不固定首尾帧。场景图单独控制空间/光照。先核对具体接口是否能理解此类板，不把多个同身份视图自动当成多个替换主体。

已有明确视频生成请求且素材已就绪时，交给项目 `video-retargeting` / 已安装 `clay-video-retargeting` 和 `autodl-aigc` 继续；只有做角色板的请求不会启动收费视频。**运动格不是动作时序控制**：原片腿脚仍驱动出脚时，应适配白模下身，不能继续机械追加更多站姿图。
