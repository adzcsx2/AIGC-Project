# 人物三视图参考板

新人物、动物及其他非人角色先按 [新角色三视图前置与API绑定](../../../docs/工作流/character-voice.md#新角色三视图前置与api绑定) 制作独立三视图，再用于场景图及下游API身份输入；不先在场景里临时生成角色。该步骤属于已授权制作的必要前置，无需另点名本技能；只写文案/提示词或维护规则仍不生成。无原图时从已确认外观与本片style直接制作，已有合格同身份三视图可复用。

同一人物的板、原图与造型引用同一角色YAML，规则见 `docs/工作流/character-voice.md`。只有剧本需要人物说话时才配置声音；只制作参考板时不要求用户先选声音，也不为增加名字而改图；显示名与剧情称呼分离。

用户给一张图并要求人物视图时，实际看图、按固定三视图排版、调用允许的图像工具生成、检查再交付同一张板；只要求提示词时停在文本，只维护规则时不生成。不能把原图镜像当背面，也不声称能从一张图恢复不可见的真实背面。

## 输出约定

用户2026-11-10确定：同一张板**仅正面特写、正面全身无头、背面全身**。按 [三视图版式与用户基准图](references/版式与三视图.md) 执行；正面身体只显示颈部以下至脚底，背面保留完整后脑至脚底。省略头部仅是正面身体视图的展示方式，不改角色实际解剖。

禁止自动加入侧面、侧脸、俯仰视角、运动姿态格、表情格或其他视图。视频有爬行、飞行等动作或镜头变化也不构成加格理由；只有用户以后明确另定视图时才改变。已有合格参考板可复用，不为新标准重做所有老素材。

## 先审计参考

作品涉及相对体量时，按 [导演流程「主体与物体的尺寸约束」](../../../docs/工作流/director-workflow.md#主体与物体的尺寸约束) 沿用确认依据。角色板各格按展示用途排版，不用格子/头像大小推定角色在场景中的真实尺寸，也不为作比尺擅自在单角色板中添加另一演员或重做已合格素材。

1. 有原图时看全幅和头部，记录脸型五官、发型/毛发/鳞片、颜色、配饰、服装（如有）、不对称痕迹、身体比例和肢体/尾翼数量。无原图时从已确认角色设定读取这些锚点，不虚构看图记录，也不强制先生成单张立绘或场景角色。
2. 区分原图可见事实与新补设计。只有半身时，全身下部和背面按已见材质/结构保守延续；不无故添武器、发饰、尾巴或推进器。缺少决定性设定才问；一般遮挡细节合理补全并在交付说明。
3. 动物/非人角色保持真实头部、躯干、肢体/尾翼和支撑结构；四足动物不强制双足站立，不强加人类服装，蛇妖不得新增人腿，机甲不虚构面甲内人脸。仅在身体结构确与原片动作冲突时查看相关帧并登记视频适配缺口，不因此增加运动视图或启动视频。
4. 原图背景只用于理解原图，不自动带入身份板。默认灰底、柔和均匀照明、清晰轮廓；场景母图另存。场景动作关键帧是另一用途，不能把此板当成固定首帧。

## 版式与提示词

按 [三视图版式](references/版式与三视图.md) 分配画面：默认16:9横板，左侧正面无头全身、中间背面全身、右侧大幅正面特写。两个身体视图按同一身体尺度、脚底基线排列，不为顶端齐高拉长无头身体。尾尖、鞋与固有翼尖保留，特写不遮挡身体视图。

先读作品 `project.yaml.documents.style` 及实际身份图，再按 [英文提示词写法](references/英文提示词写法.md) 写具体正文，落实本片材质、光影和画风。示例只作排版参考；使用 `s-grade-3d-prompts` 时只取适用的一致性方法，不套其旧四/五/六视图、运动格、人物或画风。三个视图各写独立裁切范围，不能笼统要求每格完整头部或每格都无头。

交付或调用前按导演流程「提示词迭代审计」再次检查：恰好三视图、正面特写朝向、仅正面身体省略头部、背面完整、左右与不对称细节、同一身份/造型、风格依据、身体结构与支撑、参考职责、画幅和真实工具参数。发现冲突先修改再全局复核，全部适用项通过才定稿；模板说明和占位符不直接发送给模型。

## 生成与工具选择

- 在本项目，用户明确要求生成参考板，或已授权制作需要新角色（含动物）三视图前置时，使用内置 `image_gen`，优先于旧的仅MJ提示词流程；用户另定工具时遵从。只写文案/提示词或维护规则时不生成媒体。先读可用的 `imagegen` 技能。
- 本地输入先用 `view_image` 看图，然后通过 `referenced_image_paths` 传入；只有对话图片且无本地路径时按工具规则使用最小的 `num_last_images_to_include`，二者不能同时传。灰底是不透明背景，`transparent_background: false`。优先一次生成完整板，避免各角度独立抽样造成换脸。
  从已确认文字设定新建且没有实际参考图时，不填图像引用参数，不把排版示例当作该角色身份图；不为调用编辑参数先生成无关人物图。
- 用户明确选择Midjourney则只交英文正文、挂图顺序与实际参数，遵守 `docs/工具与接口/midjourney-local.md`；不自动操控网页提交。普通Imagine与Editor分开处理，MJ参数不塞给内置image_gen。
- 即梦工作台只作为用户想要的功能形态说明，不据此声称已接通即梦或替用户调用未配置服务。

## 实际验收与定向修正

查看全板，再逐格放大检查，不能只看缩略图或因为提示词写了“一条尾巴”就通过：

- 视图数量与范围：恰好三个；正面特写正对镜头，正面身体颈部以下至脚底完整且没有头脸，背面严格背对镜头且后脑至脚底完整。无侧面、侧脸、运动格或额外小图。
- 身份与风格：五官、妆发、服装、色彩、材质及不对称细节一致；背面补设计可与正面相接。排版示例不能带来换脸、换装或画风漂移。
- 结构与支撑：逐个身体视图从根部追踪肢体/尾翼至末端；蛇妖保留连续唯一尾巴，无分叉或人腿脚，站姿按真实身体支撑。正面省略头部不等于角色本身无头；画面不能出现伤口、断头道具或多余头部。
- 排版：左正面身体、中背面、右大特写；两个身体视图尺度和脚底基线一致，省略头部后的高度差合理。手、衣摆、鞋及结构末端完整，不跨区连接或被特写遮挡；正面特写脸部细节可读。

有缺陷时先定位具体格与错误，保留已合格部分及原身份图，使用image_gen进行局部/整体定向重生成并复查；**默认最多两次定向修正**，用户另有明确迭代范围则遵从。仍不合格时交代失败项及最小缺口，不无限循环或把待修图标ready。这是角色板修正范围，不自动授权新增收费视频重抽。

合格图保存到 `projects/作品名/02-素材/人物/人物-角色名-三视图参考板-版本01.png` 等实际中文路径，保留真实格式、原图及版本。交付整板、实际保存路径、简短通过项/补设计说明；不把模板路径当成现存素材。

## 进入视频

先核对 [实际三视图绑定契约](../../../docs/工作流/character-voice.md#新角色三视图前置与api绑定)：每个新角色的合格三视图须在实际支持的API参考槽中传入，不能只有场景图或prompt文字。入口不兼容时先解决方案，不把三视图塞进场景首尾帧字段。

角色板控制一个角色的身份、服装和身体结构，不复制灰底、格线、排列或正面身体的省头展示，不固定首尾帧。视频中的角色保留正常完整头部。场景图单独控制空间/光照；先核对接口是否能理解此类板，不把三个同身份视图当成三个替换主体。

已有明确视频生成请求且素材就绪时，按 `docs/skill-routing.md` 返回原任务：保留源视频动作/运镜走 `video-retargeting` 与其白模适配；原创走总导演当前阶段，再由 `autodl-aigc` 执行。只有角色板请求时交付归档，不启动视频。**三视图不控制动作时序**：运动方式、节奏、路径和接触交实际引导及英文视频正文；结构冲突需适配引导，不追加视图来代替。
