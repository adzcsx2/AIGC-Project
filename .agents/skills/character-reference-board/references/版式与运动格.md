# 版式与运动格

## 一张板中的视图职责

| 格 | 检查目标 | 要求 |
|---|---|---|
| 正面全身 | 身份、服装前片、体型 | 正对相机，完整头部和身体末端；常态结构，不强制所有物种站双脚 |
| 背面全身 | 后脑、后衣、装甲/尾翼连接 | 同一角色转身后的真实背面，不用正面镜像 |
| 严格侧面全身 | 轮廓、厚度、身体连接 | 90度，默认角色左侧可见、面朝画面左；不以三分之四视角代替 |
| 正面脸部 | 五官、眼睛、妆发、识别痕迹 | 独立近景，脸清楚，不被头饰和头发完全遮挡 |
| 严格侧面脸部 | 额鼻唇下颌轮廓、耳饰位置 | 与全身侧面同一侧，保持不对称标记属于角色原来的身体侧 |
| 目标运动 | 支撑、发力、推进部件、身体连接 | 展示目标运动中最有辨识力的一瞬；不是多个残影叠在一起 |

默认16:9横板，上排三格全身；下排两个较小脸部格＋较宽运动格。头部格画面大小不要求等于全身格；全身不同视角保持相近真实比例与基准尺度，尾巴自然展开可占不同宽度。必要时调整为不等宽布局或更适合长尾/展翼的画幅，不牺牲五项基本视图来凑等格。

不要要求全图“只有一颗头”：该指令会与多格板冲突。应写每个身体视图一颗头、每个脸部视图同一颗头；所有格是同一身份的展示，不是同一场景多个演员。

## 运动格选择

| 目标运动 | 应看清 | 应避免 |
|---|---|---|
| 人形步行 | 承重脚、摆动腿、骨盆与上身协调；自然迈步瞬间 | 悬空两脚却标步行；静态站姿假装走路 |
| 蛇妖低姿爬行 | 侧前机位，上身前倾降低，腰到宽腹鳞再到唯一尾尖连续，腹面接触灰色地面，手臂按需辅助支撑 | 另长人腿脚、蛇尾从两处长出、尾尖蛇头、站姿拖着尾巴、交叉遮挡连接 |
| 有腿角色四肢爬行 | 原本的双臂双腿保留，手掌/膝或脚趾的真实支撑、重心降低 | 误套蛇妖去腿模板；上下肢数量变化 |
| 机甲推进飞行 | 同一装甲比例和部件数量，明确离地，身体俯仰及手脚收放，原有喷口/翼面位置可见 | 为表示飞行凭空加喷口或翅膀；删掉原有腿；喷焰遮掉结构 |
| 有翼角色飞行 | 翼根、左右翼数量与展开方式，身体重心及离地姿态 | 多翼、断翼、背景云遮挡关键连接 |

姿态板表现一瞬，不能证明真正运动的周期、转弯或轨迹；动作引导视频仍需单独验收。不预设所有机械角色都需要飞行，使用用户指定的移动方式。

## 与其他板的关系

- 正背侧＋面部正侧是用户本次指定的身份基线。原项目“正背俯仰四格”只覆盖另一种用途，不能代替这里缺失的侧面与脸部侧面。
- 视频确有俯视/仰视且需要额外结构时，可增加视角或另存补充资产；不默认每次塞到八九格而使细节不可读。
- 灰底人物板可跨场景复用；场景变化单独换环境参考，人物衣服及受光在视频里自然接受场景光线，不把影棚光固化到最终成片。
- 对已通过的蛇妖双姿态板，扩展新五/六视图是新资产准备；不能声称六视图板已经通过H3实测。用户没有要求重做的旧合格素材继续可用。
