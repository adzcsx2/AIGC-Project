# 视觉资产与图片提示词

先读 `AGENTS.md`、`docs/director-workflow.md`；MJ参数与入口见 `docs/midjourney-local.md`。
所有路径相对项目根。中文请求自动整理成英文模型正文，中文用途说明、参数卡、素材文件名保持中文。

1. 从已确认剧本和分镜提取身份、服装变体、场景、道具、伤势等状态；先查素材目录并实际看图。
2. 输出缺口清单：素材ID/用途/影响镜段/已有文件/缺少内容/补法/中文保存名，不能把提示词当成现成图片。
3. 为每张图单独决策参考槽位与顺序、控制范围、画幅、动作留白和Aesthetics参数。
   MJ普通Imagine默认V8.2，复制正文附实际版本、画幅和采用参数；Editor/Layers分开处理。
   交付英文正文与中文挂图说明，用户在官网手动生成；不恢复Discord自动化。
4. 角色需要多角度/运动格时转 `character-reference-board`，已合格图可复用，场景图独立。
5. 同场景按选定母图写具体空间、建筑、纹理、光线锚点。动作图先看视频代表帧，写明确人物占比和活动空间。
6. 交付前二次审计朝向/左右手/持械、身体结构、动作模板冲突、参考干扰、场景与参数；图回来后实际再查。
7. 前置条件满足的多张图一次批量交付；候选待用户选定，专项参考板已有自主验收授权时按该授权执行。
   通过后中文归档并更新materials状态，自动推进已确认的下一步。

## 内部方法来源

资料根 `.agents/resources/skills/`：
- `short-drama-assets/references/`：身份、变体、世界状态；先做登记再写提示词。
- `short-drama-image-prompts/references/`：构图与引用职责；由本入口统一交付。
- `s-grade-3d-prompts/SKILL.md`及按用途的references：用户提供的材质、人物、3D动作与特效方法。
  保留来源原文，但本项目新提示词全英文；打斗默认3D CG，不采用旧“不要3D/CG”负面词。
- `short-drama-review/references/`：资产与提示词审计，自动按阶段执行。

原人物示例、固定比例、历史模型参数不是当前任务事实。未确认补全文案时不开始下游制作。
