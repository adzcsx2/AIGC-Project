# 视觉资产与图片提示词

人物归档按 `docs/工作流/character-voice.md` 登记到作品的独立角色YAML；多个造型/参考板引用同一人物ID，显示名可空。人物建档不要求先配声，仅剧本需要说话时进入配声流程；声音设计须实看已选图，由总导演集中交试听，图通过不代表音色已确认。

新人物、动物及其他生物遵守 [三视图前置与API绑定](../../../docs/工作流/character-voice.md#新角色三视图前置与api绑定)：先交character-reference-board生成/验收独立三视图，再以其为身份参考制作含角色的场景、端点或衔接图，并核对下游请求实际传入三视图。不得在场景里临时设计新角色，再仅将场景图送API；纯环境、道具及不依赖身份的已授权工作可继续。

先读 `AGENTS.md`、`docs/工作流/director-workflow.md`；MJ参数与入口见 `docs/工具与接口/midjourney-local.md`。
所有路径相对项目根。中文请求自动整理成英文模型正文，中文用途说明、参数卡、素材文件名保持中文。

多片段按 `docs/工作流/multi-segment-video.md` 的跨段切镜设计准备素材：前段出镜与后段入镜可为不同机位/景别，不再默认N−1张共享图。Codex内置image_gen据已看身份/场景及预演准备真正需要的镜头图和端点；复用合格素材。此专项优先普通MJ手动、不套MJ参数，镜头图表现真实动作/状态与空间。
前置条件就绪的图批量准备，记录每张连接的两个片段与文件哈希；若本批接受后即生成视频，先交cinematic-script-audit完成当前方案总审计并展示结论，再交最终审图/生成决策材料，不能等用户确认后才审。明确连续例外才同图绑定前尾后首；一般切镜分别登记前出/后入图。按实际用户确认或作品限定自主验收授权置ready，不能伪造为用户逐图认可。不等前段视频才制下一张图。用户改共享边界时说明受影响相邻段，未经确认不扩大重做。

视频用途的最终端点/镜头图按 [默认先做白模](../../../docs/工作流/白模制作与验收.md#默认先做白模) 以实际预演复核，已有候选允许保留调整，不能拿静图代替路径/摄影检查；单独图片请求不因此启动白模或视频。

1. 从已确认剧本和分镜提取身份、服装变体、场景、道具、伤势等状态；先查素材目录并实际看图。
   先读取本片 `project.yaml.documents.style`，按导演流程「项目风格与防漂移」分清身份/材质风格/环境用途并确认参考能支撑目标景别；每张实际英文提示词带适用风格要求。近景依据不足才补图，不把其他作品默认风格或静态站姿覆盖本片，不擅自更换已选参考。
2. 输出缺口清单：素材ID/用途/影响镜段/已有文件/缺少内容/补法/中文保存名，不能把提示词当成现成图片。
3. 为每张图单独决策参考槽位与顺序、控制范围、画幅、动作留白和Aesthetics参数。
   MJ普通Imagine默认V8.2，复制正文附实际版本、画幅和采用参数；Editor/Layers分开处理。
   交付英文正文与中文挂图说明，用户在官网手动生成；不恢复Discord自动化。
4. 人物参考板转 `character-reference-board`，只做正面特写、正面全身无头、背面全身；不因动作需求加视图。已合格图可复用，场景图独立。
5. 同场景按选定母图写具体空间、建筑、纹理、光线锚点。动作图有原视频先看代表帧；原创无源片时按已确认动作/分镜与可用预演评估最大展开，写明确人物占比和活动空间，不虚构已看原片。
   体量影响构图/互动时，应用 [导演流程「主体与物体的尺寸约束」](../../../docs/工作流/director-workflow.md#主体与物体的尺寸约束)：以相容的体量类比、同场相对比例和可握持/承托参照表达大小，区分实体尺寸与画面占比；类比不换身份、不新增此刻动作，返回图按实际同框关系核对。
   人物剧情图按根规则及导演流程「表情、情感与镜头表现」写具体表情、情感和匹配的肢体姿态，英文正文落实可见细节；单图只选一个情绪瞬间，组图按剧情变化，不能每张都是同一种微笑/站姿或堆相互冲突的先后表情。身份参考板与无人物图按用途处理。
   涉及实际互动时按导演流程「真实接触与物质反馈」描写此瞬间的接触几何、支撑和对象/液体状态，避免悬空抓握、穿模或舌头触液却奶面完全不受影响；衔接图保持接触相位与物质后果，不把完整先后过程塞进单图。
6. 交付前二次审计表情/肢体与情境及构图是否一致、朝向/左右手/持械、身体结构、动作模板冲突、参考干扰、场景与参数；图回来后实际再查。
   同时检查上述接触反馈；按导演流程「提示词迭代审计」对不符项继续修改并复核全局一致性，直到所有适用要求通过才定稿/交付/提交，不以审过两遍结束；缺真实证据或待用户决定时明确标未通过及具体缺口。
7. 前置条件满足的多张图一次批量交付；候选待用户选定，专项参考板已有自主验收授权时按该授权执行。
   通过后中文归档并更新materials状态，自动推进已确认的下一步。

## 内部方法来源

资料根 `.agents/resources/skills/`：
- `short-drama-assets/references/`：身份、变体、世界状态；先做登记再写提示词。
- `short-drama-image-prompts/references/`：构图与引用职责；由本入口统一交付。
- `s-grade-3d-prompts/SKILL.md`及按用途的references：用户提供的材质、人物、3D动作与特效方法。
  保留来源原文，但本项目新提示词全英文；打斗默认3D CG，不采用旧“不要3D/CG”负面词。
- `short-drama-review/references/`：资产与提示词审计，自动按阶段执行。

原人物示例、固定比例、历史模型参数不是当前任务事实。未确认补全文案时不开始下游制作。
