# 入场特效与声音

来源：打斗DOCX第4、7～12、16～17章。只在已确认剧情需要对应内容时使用。
暗黑神兽、法相与天地异象是题材模块，不是每张人物图、每个生活镜头的必需项。

## 出场服务人物分量

常规交战尽快进入有结果的动作，避免长空镜与重复蓄力；若当前段落重点是强者/觉醒登场，
给局部揭示、表情、空间尺度留时间。原文的6～12秒高光是叙事参考，不能在15秒里再机械叠加全部打斗模块。

按剧情选择一种主机制：

| 机制 | 连贯视觉变化 |
|---|---|
| 天降 | 云层/光柱预兆 → 人影显露与视线锁定 → 沿已定路径下降 → 双脚落地、余波扩散 |
| 空间踏行/镜面破裂 | 裂痕扩散 → 通道形成 → 足部踏出 → 全身穿过 → 碎片消散 |
| 浪/岩浆/能量海 | 流体受力改变 → 浪峰承托 → 角色沿浪轨迹入场 → 浪迹与落点衔接 |
| 雷、火、冰苏醒 | 环境先兆 → 能量/冰壳结构变化 → 身体显露 → 凝视敌人 → 残留元素状态 |
| 法相/双生法相/一指威慑 | 粒子聚拢 → 轮廓凝形 → 姿态与纹理稳定 → 视线或手势启动 → 空间受压 |
| 植物、引力奇点、镜像分身 | 交代生成中心和方向，再写形成、主体显露和收束；分身不是误生的额外人物 |

表情可用眼睑微动、视线聚焦、嘴角变化、下颌发力；角色性格不一定傲慢。
入场时已经受伤的人物仍保留伤势，不能为“不可一世”删掉必要的吃痛和疲劳反应。

## 特效具有形成、作用和结束

大型技能可用“环境预兆 → 能量汇聚 → 结构成型 → 核心激活 → 释放/作用”的渐进逻辑。
小技能压缩过程，预设已经存在的法阵/实体不强行重新召唤。
施法手势或武器动作是可见因果：写哪只手、关节如何发力、能量从哪里离开、对手如何回应。
手还没动就完成释放、站桩只换光效都不合适。

大型异象优先放在背景余光、表面反射和光照变化中：主角动作始终可读。
交代异象在哪个方向、由哪次攻击触发、如何改变脸/衣服/武器上的光，收尾如何消散或保留。
不为“第一帧必须异象”把正常天空强行换成雷暴，更不能破坏已选云宫等场景的连续性。

双角色可建立服饰主色、武器色、攻击色、拖尾色、碰撞粒子色映射。
颜色归属稳定，碰撞时也能读出双方来源，不因“特效拉满”全部变成混色光团。
无文字画面中的法阵使用抽象非文字纹样；策划箭头只留在说明或经授权的分镜示意里，不让成片出现UI箭头。

## 神兽只按已选方向塑造

暗黑写实方向取粗粝/磨损鳞片、毛发分叉、角质裂纹、湿润眼睛、泥水痕、低饱和暗色与局部轮廓光。
动作具有大型动物的惯性与重量，体量用已确认的世界尺度和前景人物对比表达。
光明仙侠或其他已选风格沿用其审美，不能因为原文“强制”就变暗黑腐败生物。

| 类型 | 可选的识别/动作锚点 |
|---|---|
| 龙 | 鳞片、须、爪数和身体盘绕方向；吐息、爪击或尾扫选当前剧情所需 |
| 凤凰 | 羽毛层次、翼展与尾羽；燃烧状态和灰烬方向需与风向相符 |
| 麒麟 | 角、鳞甲与足部承重；踏地或角部放射须有明确作用路径 |
| 玄武 | 龟甲与蛇身的明确结构、头尾位置；水冰反馈遵循既定元素 |
| 九尾狐 | 九条独立尾巴、固定眼睛数量和狐火归属；不把“九双眼睛”误当九尾本体结构 |

召唤过程可从轮廓到表面细节到眼神激活，不必表现剥离肌肉的解剖过程。
当前为战斗同盟时，召唤者手势与神兽行动协同并锁定同一敌人，不意外变成抚摸宠物的镜头；
剧情本来需要亲昵互动时，不能套用这一战斗限制。

## 同步声音

- 新创作且模型支持音频时，将声音绑在发生动作的同一句/时间段：武器破空、金属接触、身体受击、
  地面/枝叶、能量、环境底噪分别承担信息，重音落在实际接触瞬间。
- 低频用于重量与余波，高频用于切割与金属，空间混响匹配场景尺度。
  “虚空混响”适用于当前超自然声音，不能让全部对白都强制变低沉反派声。
- 保留剧本既定台词与语言，使用模型已核实的对白标记。受伤痛呼如需中文则在中文指令中保留中文对白，
  禁止把“只需口型”误写成角色受伤完全无声无反应。
- 原视频换角/动作迁移默认保留原音轨；不叠加本库音效或自动去轨。用户要求静音时另按项目已验证路线处理。
- 无字画面与有声对白相容。字幕、技能名、Logo、水印、时间码是否允许，以当前作品需求为准。
  不把原文“两句、每句2～6字”当所有剧情的对白上限。
