# 人物与画风

来源：人物DOCX男性/女性示例，以及TXT的皮肤、发型、服装材质和影棚光描述。
原例定位见[来源与适配](来源与适配.md)。以下英文是可选词汇片段，需结合当前图重组、审计，
不是可以直接提交的完整提示词。

## 先选一种主媒介

| 用户已有画风/当前用途 | 可提炼的英文表达 | 取舍 |
|---|---|---|
| 写实国漫、精细CG角色 | `high-end Chinese fantasy 3D character rendering`, `physically plausible materials` | 保留角色模型化的造型，不自动变真人摄影 |
| 仿真或真人感 | `photorealistic character portrait`, `subtle natural skin texture` | 保留真实皮肤起伏，避免磨皮塑料感；身份以参考为准 |
| 半厚涂、拟真插画 | `semi-realistic painterly CG illustration`, `restrained visible brushwork` | 笔触与体积协调，不同时强求完全无笔触的照片 |
| 三渲二 | `cinematic 3D-to-2D rendering`, `controlled hand-painted linework` | 用于已选三渲二方向，不给所有仿真角色加描边 |

本项目打斗主媒介默认3D CG；三渲二只在用户明确另选时使用，不作为自动混搭项。
一张图只设一个主媒介，其他描述服务该媒介。已有图时不要因为原文常用冷白皮、BJD脸、银发、
九头身、暗黑妆容而覆盖当前人物。原文的少年感、1.8米和腿长60%都是个例。

## 人物描述顺序

身份识别点 → 当前表情/视线 → 发型及饰品 → 服饰结构与材质 → 手脚和道具 → 构图 → 光影环境。
人脸特写突出五官与细微表演；全身图把身体、双手、鞋和服装轮廓的可读性放在面部微距之前。

| 模块 | 取用方法 | 英文词汇片段 |
|---|---|---|
| 脸与皮肤 | 脸型、眼型/瞳色、眉形、鼻唇各保留少量可辨识特征；自然皮肤有纹理 | `defined facial planes`, `subtle skin microtexture`, `soft subsurface scattering` |
| 眼神与表演 | 写看谁、看向何处、眉眼/下颌如何改变，区分清冷、疲惫、警惕 | `a focused gaze toward the distant opponent`, `a tense jaw` |
| 发丝 | 锁颜色、长度、分缝、束发结构与饰品位置，再写风向 | `individually resolved hair strands`, `layered strands moving with the wind` |
| 丝绸与薄纱 | 区分缎面高光、薄纱透光、织物厚度与垂坠 | `soft satin sheen`, `translucent layered gauze`, `weighted fabric folds` |
| 金属与珠宝 | 指定部位、材质和数量，控制反光，不用“超多配饰”重设计服装 | `engraved silver fittings`, `subtle pearlescent highlights` |
| 厚涂肌理 | 限制笔触落在合适表面，避免把脸与衣纹全部抹糊 | `delicate painterly texture with clearly readable facial features` |

“无冠无束”与“巨型发冠”、“头发不遮脸”与“长刘海盖眼”、“面具盖满脸”与“清楚展示全部五官”
不能并列。选定具体状态，另一个只作为历史例子留存。

## 光色和空间

- 从当前参考提取主光方向、冷暖、阴影软硬和背景明度，再选择柔光箱、侧逆光或伦勃朗式布光。
  不叠加多个互相竞争的主光源。身份/服装板优先清晰柔光，剧情镜头按原场景光照。
- 写清主色、辅色和点缀色各在哪里；例如服装、金属饰件和能量各自归属，不只写“高级配色”。
- 光影词可选 `soft key light from camera-left`、`subtle hair rim light`、`controlled highlights`、
  `cool ambient fill`；方向须按当前镜头改写，不把片段的左侧当统一规定。
- 真实皮肤细节与柔焦可以分区：脸与衣物关键结构清楚，非关键背景柔化。
  全身/多视图需要鞋、袖口、背部结构都可读，不照抄TXT的 `f/2.0` 浅景深。
- 人物身份板可用干净影棚背景；进入同一场次后，改写为已选环境的具体空间锚点。
  禁止把“随机背景”带入场景连续性要求。

## 删去无效和冲突堆词

8K、32K、888K、“极致/最高画质”不等于真实输出分辨率；UE5、Octane、C4D、Blender在这里最多是
视觉参照，不能宣称模型实际运行这些渲染器。用材质、光向、细节尺度和画面层次表达想要的结果。
普通图的版本与实际画幅/Aesthetics按项目Midjourney规则另填，历史“模型4.0”等不转成参数。
