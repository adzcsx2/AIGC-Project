# 打斗动作与镜头

来源：打斗DOCX第1～8、10.5～10.13、13～15、18章。原文中的频率、角度和帧数属于示例强度，
不是模型可精确执行的保证。结合武指与H3表演技能使用。

用户已确认打斗要求 **3D CG**：保留立体建模、真实材质、空间光影和重量感。
原文的2D水墨、三渲二等分支不自动采用，“不要3D/不要CG渲染”等负面词不进入3D打斗正文。

## 先定动作事实和空间

- 锁每人身份、武器数量/形制、左右手、朝向、距离、垂直高度、胜负或中断状态。
  弓手/法师等远程职业维持整座场地远端距离，单人镜头的对手在画外远端。
  原文“1秒内重新近身”不适用于远程对决。
- 用“起点 → 路径 → 落点 → 接续动作”记录每次位移，保留地面裂纹、台阶、柱、栏杆等世界参照。
  武器脱手后追踪飞行与回收过程，不能切镜后重新出现在手中。
- 同机位保留位置与透视；换机位说明镜头如何绕行或越过动作轴，按同一世界空间重新描述屏幕方位。
  不把“永远居左/居右”当跨机位物理规律。双方真实体型稳定，但远近差异允许正常视觉大小变化。
- 空间锚点包含已选场景的建筑形制/数量、前中后景关系、地面纹理尺度、栏杆走向、云层高度、
  光向、阴影和色温。不能只写 `consistent scene`，也不为强化破坏擅自毁掉既定建筑。

## 用动作链承载因果

连招按“动作主体/左右肢体 → 支撑与重心 → 轨迹 → 接触位置 → 双方反馈 → 下一姿态”写。
高速段落可压缩修饰词、连续用具体动词，但保留谁先动、谁如何挡和落点，避免一串招式失去主体。

| 模块 | 具体选择 |
|---|---|
| 蓄力 | 支撑脚压地、膝肘适度弯曲、腰胯转动、肩臂后引；不把僵直站桩发光当发力 |
| 发力 | 蹬地经髋腰传到肩臂；腿部从屈膝到甩出；写攻击点、方向和目标位置 |
| 命中/格挡 | 接触点明确，受力者沿力线后仰/屈膝/滑退，攻击者有反作用力并回收肢体 |
| 环境反馈 | 积水扇形飞溅、泥点随脚步甩出、地面犁痕、枝叶沿气流偏转；范围与攻击相称 |
| 结果 | 沿已确认分镜写占优、险胜、带伤对峙或明确外力中断，不擅自决定倒地和死亡 |

英文动词可选 `slash`, `sweep`, `thrust`, `parry`, `deflect`, `pivot`, `sidestep`, `slide`,
`spring upward`, `recoil`, `stagger`。每个动词仍需绑定角色与方向，不能只写 `attack fiercely`。
不照抄原文中“关节完全锁死”或不合当前姿态的角度；以自然身体协同和清楚受力为准。

远程投射物的描述可包含 `a detached free-flying projectile streaking across the vast terrace from off-screen`，
并说明箭、冰刃或光矛的形制、飞向和命中部位。远程法杖施法不能变成近身戳刺。

## 镜头由动作决定

| 动作/信息 | 运镜选择 | 需要保留的读图信息 |
|---|---|---|
| 滑步、贴地突进 | 低机位横向跟拍 | 支撑脚、地面参照和前进方向 |
| 腾空或坠落 | 向上跟升/下摇 | 起跳点、垂直高度和落点 |
| 横斩、横向闪避 | 水平跟移或有方向的甩镜 | 刃轨、对手与接触点 |
| 绕背、环绕 | 围绕已定中心的弧形跟拍 | 双方距离与动作轴变化 |
| 重击或落地 | 短暂停顿、轻微沉落回弹 | 身体受力与打击点先可见，再加相称震动 |
| 飞行投射物/远程施法 | 远景交代距离、跟随投射物或受击侧镜头 | 投射物已脱离武器，对手仍在场地远端 |
| 技能完整体、巨物 | 稳定广景或低角度揭示 | 原角色比例、技能尺度和明确空间 |

关键动作需完整可读，不机械要求每秒3～4次切镜、每5秒4种景别或每段8连招。
用全景交代空间、中景读动作、特写读表演/接触点；时间不足时减少事件数量。
切镜可用动作匹配、同向运动、甩镜或短暂遮挡，不靠白闪掩盖无法衔接的动作。

ACT越肩/背部跟随用于短暂近身交锋或追击；需要时用中全景重新交代空间。
原文建议的ACT约30–40%、单段不超过3秒仅作参考。远程对决无需为了占比强加贴身ACT镜头。
第一人称须看得到当前动作涉及的自身武器或肢体；技能凝聚优先稳定电影机位。

## 打击等级、速度与效果

- 轻格挡：局部火星/材质粒子、短促金属声、小幅回弹。
- 重命中：清楚身体受力、相称地面/道具反馈、极短顿挫与一次镜头冲击。
- 终结/大招：先确认动作与结果，再用环形气浪、集中光效、拉远展示影响范围。

物理姿态与环境反馈优先于冲击波，冲击波优先于发光。墨效冲击帧、负片、鱼眼、白闪只适用于
已选相应风格，不能固定全开。慢动作只服务关键可读瞬间，正常速度负责动作链。
原文精确到0.05秒或1～2帧的数值是效果意图，不能保证生成模型逐帧实现。

残影只在最快运动段使用：它位于本体已经经过的路径后方、姿态滞后、与本体分离、由近及远变淡后消失。
可用 `fading afterimages trailing behind along the completed motion path, separated from the solid body`。
不写“围绕身体的多层半透明叠层”，不让残影成为额外角色。速度线/模糊方向跟随动作，面部和打击点仍需可辨。

## 受伤与跨镜状态

- 命中造成受伤就写可见吃痛：冲击后仰/踉跄、皱眉咬牙或痛呼，以及手掌按伤口/手指抓箭杆等具体动作。
  不能受伤后无停顿、无表情直接出招。受击不等于必须血腥，伤势等级遵守分镜。
- 箭、冰刺或兵器未拔出前，后续每个出现该角色的 `[Shot N]` 都显式重申原部位嵌入物、伤口、血迹。
  例如原剧情确为左肩中箭时才用 `with the crimson-feathered arrow still deeply embedded in her bleeding left shoulder`。
  不能把示例的左肩或红羽箭套到其他伤势。
- 衣物破损、疲劳、汗水、跛行与环境破坏随剧情持续；不按“第几次命中必定升级到重伤”的原表机械加伤。
  清洁角色母图只管身份，不得冲掉当前伤势状态。

## 15秒结构的取用

普通连续打斗可按0～3秒进入冲突、3～8秒攻防升级、8～12秒关键转折、12～15秒结果与余韵规划。
这些是内部时间段，不是四个独立生成任务。默认以多视角角色板+场景母图（或已确认母板/首帧）
完成一次15秒连续多机位H3视频，标记和实际时长以该工作流规则为准。
表演重心是高光出场时，改用入场结构并减少碰撞，不能同时塞满长登场、神兽凝聚和八连招。
