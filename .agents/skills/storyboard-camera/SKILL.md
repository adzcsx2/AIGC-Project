# 分镜与摄影

按 `docs/工作流/character-voice.md` 只标明每镜剧本需要说话的人物ID与声音来源/参考槽，显示名不自动写成台词称呼。无台词/非语言声不要求配置音色；需要说话但缺声只列该镜依赖，继续独立分镜和视觉工作，交workflow末尾集中试听；声音未接受的说话镜头不能标ready。

先读 `AGENTS.md` 和 `docs/工作流/director-workflow.md`（路径均相对项目根）。文案缺动作/因果时先交
`fight-scene-design`或`short-drama-workflow`补全并让用户确认，不提前写最终分镜和提示词。

先承接 [电影级剧本基准](../cinematic-script-audit/SKILL.md) 的当前设计；需要写/改剧本时必须先应用该基准，再做动作/运镜。默认16:9横屏，生成/剪辑默认24fps，最终成片自动补到60fps，不考虑平台UI安全区域，保留头脚和兵器动作余量；用户指定及已确认规格优先。专业摄影审计完成后交该技能作全局总审计并修正，在展示结论之后才提醒/询问是否生成，不能把它拖到用户确认之后。

## 拆镜与选择

多片段先读 `docs/工作流/multi-segment-video.md`，区分“模型在一次生成内执行切镜”与“用首尾衔接图连接独立片段”。按状态变化、动作容量、真实模型长度、端点可达性与局部重做需求决定段数/秒数，记录入出态、时间范围、首尾图、工作流及理由；可混合采用，不机械15秒均分。N段需预设计N−1处可见切镜或有动机转场，连续速度链尽量放进≤15秒同一次生成；在剧本和实际英文正文写切出触发、新机位/景别、第一拍动作、视觉锚点和声音承接。前出/后入图可不同，不默认共享图伪长镜头；原片严格复刻与明确连续例外按原范围。

1. 按叙事信息、动作相位和时长拆小段，记录段首/段尾位置、朝向、运动趋势、接触、道具、伤势、环境。内部边界另写最后一拍仍在执行的动作、方向/速度趋势、何时经过边界姿态，以及下一段从第一拍如何继续；静图相同不代表速度连续，禁止提前摆成尾图后等待。
2. 选景别、机位高度、焦段倾向、镜头路径/速度/目标和焦点；说明此段要看清什么、为何适合这个运镜。
   有真正取舍时列替代方案和舍弃原因，避免只堆“震撼、电影感”。每段一个主导摄影意图。
3. 从 [摄影选择表](references/运镜选择与审计.md) 定位真实示范；必要时观看相关示范而非一次加载132段。
4. 按根规则与导演流程「表情、情感与镜头表现」，主动增加有叙事作用的镜头变化：随情绪转折、关系变化和动作信息切换远近、高低、角度、运动/静止及反应视角，写明变化的具体作用。审计是否长期同侧、同景别、同速度或每镜都环绕。
   面部情绪与肢体反应应在相应节拍有可见范围；静止镜头可用于关键反应/接触，不为凑数量强切或牺牲轴线、距离闭合。
5. 写入 `分镜.md`，采用 `templates/short-drama/运镜审计.md`。逐段通过之后，再检查整体节奏与总时长。
   不把每次内部切镜机械拆成独立短视频；经分段审计选用的首尾图短段允许，源片复刻不添加新镜头。

## 摄影执行与主动作覆盖

- 按 [导演流程「主体与物体的尺寸约束」](../../../docs/工作流/director-workflow.md#主体与物体的尺寸约束) 区分实体大小、距地高度与镜头内占比；体量关键时给可比较的同场关系，并以真实机位/透视核对，不把靠近镜头或姿势变化误判成实体缩放，也不将某作品比例设成所有镜头默认。
- 原创打斗读取 [高密度导演合同](../fight-scene-design/references/高密度打斗导演合同.md) 的状态接力、速度强调与编译部分；接收fight已确认的攻防链，每段先确定要揭示的优势/距离/支撑变化，再选择机位。阶段数不等于镜头数或生成段数，不自行补胜负、兵器或改远程交战距离。
- 每镜写成可执行指令：目的、跟随主体、起点机位/景别、相对路径/速度、焦点、止点构图、切出触发和下一镜动作相位。库名称/编号只是设计依据，不能代替正文；把选中方法改写为当前角色、位置与动作，不靠增加镜头数装作丰富。
- 变化应揭示新信息：逼近距离、接触面、侧后方威胁、升空高度或受击结果。无叙事理由的同侧/同高度/同景别重复改掉，不为配额乱切或持续环绕。
- 每镜列“必须入画”：发动者发力部位、执行手/兵器、路径与接触、必要反应；需要重心/落点信息时保留脚/根基。按动作最大展开及机位移动评估余量，不只看静止首图。
- 日常互动同样按导演流程「真实接触与物质反馈」覆盖接触点、对象响应及结果：舔奶须看见触液与奶液被带起/入口、奶面受扰；抓握/踩踏/碰撞写清承重与材料反馈。镜头和英文提示词不能只跟主体动作而漏掉受作用物，反馈幅度遵守材质、力度与尺度。
- 低机位可仰拍完整身体，不等于腿部裁切。脚步/缠根/蹬地插入镜有确切进入点与退出触发，在下一次上身攻击启动前抬镜、拉开或切回；不能只写“随后跟上”“必要时抬高”。拍腿时又安排肩臂挥击，生成前即判不通过。
- 切镜/特写不吞掉主攻击起手、关键接触和结果。跨镜覆盖保持动作相位，下一镜在关键事件前建立可见范围；景深、模糊和特效不能让主动作一直不可读。
- 表演交 `acting-prompt-writer`，接收原镜头约束内的节拍后整合。可见性冲突由摄影修正，演技技能不自行改面部近景，也不删主攻击迁就取景。
- 只为fight确认的重击白名单设计接触短时停/骤慢；须看到实体接触和反冲、失衡或材料压裂。轻踢盾、蹬离、拨挡、轻击、闪避、回收和内部衔接不时停。重击强调保持同一受力相位后立即回速，不让镜头慢移延长成近一秒的人物摆姿。速度曲线与命中事件、反馈同步写入正文；以 [动作与摄影](../fight-scene-design/references/动作与摄影.md) 的判定为准。

## 模型提示词

新视频按 [白模制作与验收](../../../docs/工作流/白模制作与验收.md#默认先做白模) 默认先做简单白模，在现有分镜和运镜审计填写：每镜写出世界/相对机位、高度与角度、实际成像参数、注视/跟随目标、路径关键点、速度趋势、切换帧及动作展开余量，交对应Blender技能实现。只允许圆柱等简单几何占位，摄影设计不借机升级精细角色；自然肢体和表情编译进提示词。固定镜头写理由，复刻保留源片镜头；核对工程中的实际Camera与动画，不以字段声明或文字运镜代替实现。

- 按导演流程「项目风格与防漂移」读取本作品 `project.yaml.documents.style` 与实际基准；每个独立请求的英文正文落实适用风格核心，覆盖近景和后半段。明确身份/风格/环境/动作参考职责，风格文件ready不等于已继承；记录来源版本并核对实际配置，不让白模简化外观成为最终风格。

- 按 `docs/工作流/music-postproduction.md` 分开生成期对白与后期音乐：新视频默认仅既有对白、无BGM/歌曲/哼唱，无对白默认静音；环境声/音效仅保留明确要求，原片保声例外按任务。分镜另记音乐进入/退出的事件触发和不配乐理由，精确cue由剪辑后校准。英文视频prompt明确排除音乐，不把后期配乐设计、上游配乐模板或音乐参考音轨送进视频生成；写入前二次审计这一项。
- 全部新提示词用英文，中文需求自动译入；台词/字幕保持作品指定语言，协议引用标记不翻译。
- 由同一版已确认动作与当前分镜编译，中文导演说明和英文正文的实际切点/顺序、攻击应对、受力位移、伤势、时停、生成期声音及端点逐项一致。英文编译不能自由增减镜头；需改时先修分镜并按原规则处理实质变更。上游`BUNNY`及未安装的`h3-prompt-writing`不作为项目依赖或默认前缀。
- 白模预演后以参考图生成的原创或用户明确跳过白模的方案用u24，按实际图序绑定，不伪造ref_video；参考内部 `short-drama-video-prompts/references/minimax-h3.md` 和
  Acheng `references/70-minimax-h3-compiler.md`、`111-h3-final-format-pass-v4.md`，不是全部无差别套模板。
- 白模用titim，保留源片，使用简明英文主体映射及必要项目风格/动作约束。圆柱等简单占位必须说明身份/颜色映射、相对尺度、保留的路径/高度/接触/摄影，以及交模型补全的自然步态、肢体、表情和物理反馈；禁止照搬刚性柱体姿态或继承标签颜色。遵守实际字符容量，不套长H3分段格式，不因历史可省prompt而遗漏本次职责。
- 首尾图方案走真正接受first_frame/last_frame的入口；u24的ref_image不是首尾帧字段，具体路由由autodl-aigc核实并在方案披露。边界图规划完成后可写全部片段，不默认等前段生成。
- 上游2200–2900词不等于接口限制；由 `autodl-aigc` 校验真实字符上限、时长与媒体槽位。
- 写前实际看参考；写后再审计表情/情感递进与肢体反应是否具体且有变化、镜头是否有效承载并与中文分镜一致，以及角色朝向/左右手、攻击启动与反馈、持续伤势、光照、场景锚点、动作留白，
  清除冲突静态模板。逐段审计不能因写了“continuous”就通过。
- 全部提示词按导演流程「提示词迭代审计」执行发现问题→实际修改→复核受影响项及全局一致性的循环，直到所有适用标准通过才定稿/交付/提交；两遍不是上限，待核实或待用户决定的稿件明确标未通过。

## 按需阅读

内部源根为 `.agents/resources/`：
- `acheng-director/references/decisions/shots.md`、`20-storyboard-compiler.md`、`21-genre-camera-capacity.md`：镜头职责与容量。
- `acheng-director/references/80-continuity-ledger.md`：状态连续性。
- `skills/short-drama-storyboard/references/`：拆镜与执行字段；不采用碎片化生成默认。
- `skills/h3-storyboard/SKILL.md`：身体/关节动作表达；经验不是所有模型的禁令。
- `skills/short-drama-review/references/`：本阶段核查，自动执行，不要求用户另点“审计”。

缺图/设定交回总导演列最小缺口；摄影技能不自行调用生成API。
多片段剪辑配合总导演按 `docs/工作流/multi-segment-video.md` 的已审切镜/转场选出入点、删除多余等待；旧片或用户明确连续例外才用「既有连续镜头剪辑：版本04方法」匹配姿态、方向与速度趋势，保留必要过渡并按需压短重复准备，不固定套帧号或倍率。复杂光学转场同时核对段内启动/完成与边界速度重启风险，不能只因增加眼缘/遮罩便判为合格转场。
本阶段负责生成前的分段/摄影/提示词审计，并向总导演交每个接口的出入运动相位。多片段生成后由总导演按 `docs/工作流/multi-segment-video.md` 强制检查全部N−1个接缝的源端、合成及最终补帧结果；仅接口验收必需，不自动延伸为整片创作审计。只有实际查看结果才能报告接缝通过，不能靠提示词中的“无缝”或同一边界图推定。
