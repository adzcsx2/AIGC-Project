# 运镜选择与逐段复核

先识别观众此刻必须读到的信息，再选择摄影；以下是候选，不是固定动作处方。
视频位置：项目根 `.agents/resources/acheng-director/camera-moves-whitebox-132/`。
完整中英名称和示范索引见上级资源的 `data/camera-moves.json` 与视频目录 `清单.md`。

| 叙事/动作任务 | 适用候选示范 | 复核重点 |
|---|---|---|
| 交代交战距离、危险与退路 | 101_establishing_pull、102_master_wide、84_scale_reveal | 两人距离和空间锚点可读，不把远程戏拉成贴身 |
| 追击、逼近、并行攻防 | 44_run_chase、46_run_side、48_diag_follow、85_fast_truck | 镜头跟得上主体，距离真实闭合；不靠切镜瞬移 |
| 格挡、接触和短促反击 | 05_truck、62_wide_low、32_impact_shake | 双方关键肢体与接触点可见；震动限于反馈，不遮招式 |
| 优势反转、纵深揭示 | 24_arc_inward、67_rise_reveal、68_reverse_angle | 环绕有原因、轴线可追踪；反打不重置朝向 |
| 表情、吃痛、决心 | 104_close_up_push、106_reaction_drift、53_snap_push_hold | 特写不吃掉动作起手和下一次反击时间 |
| 投射物、视线与目标揭示 | 03_pan、34_rack_focus、83_pull_focus_deep | 交代发动者、独立飞行路径和受击端，焦点不乱跳 |
| 短暂接触时停后恢复 | 130_slow_ramp、131_speed_ramp、132_freeze_push | 仅关键拍变速，保留受力；不做整段匀速慢动作 |

上述全部是 `.mp4` 文件。库混合摄影运动、构图、焦点和剪辑示意，不能把所有项称为物理运镜。
先从已确认剧情选候选，观看所需示范并结合本镜角色/环境重新设计，不直接拿示范当当前打斗白模。

逐段检查：叙事目的→动作可见性→主导运镜→焦点与速度→首尾状态→切镜承接→素材/接口可执行性。
整体检查：信息递进、松紧变化、机位/景别/运动变化、总时长、结尾结果、是否频繁同招同镜。
同类镜头连续出现不机械判错，须写明维持它的具体原因；有无意义重复就改，不追求数量配额。
