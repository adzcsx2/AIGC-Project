本项目原有H3表演、Acheng表演适配和武指情绪资料，但没有独立的同名技能。新增入口仅负责保留原分镜的表演补充，不重复总导演、摄影或武指；原有资料继续保留作为内部参考。

| 原方法 | 项目采用与调整 |
|---|---|
| 动机推导后写外显；情绪叠加、触发、锚点 | 采用；不输出长篇心理分析，不在切镜后重置情绪 |
| 原台词、镜头与大动作不增加 | 采用；台词逐字保留，摄影/武打修改返回对应职责 |
| 未给景别默认胸部以上 | 不自动采用，避免擅改摄影及裁掉武打；查已有分镜，缺失时明确可见范围缺口 |
| 克制、明显变化少、平稳段稀疏 | 按用户2026-11-10新要求改为默认表情/情感/肢体丰富；克制仅按人物和剧情选用，不再统一小幅或固定变化数量；自然呼吸/口型与已确认动作不冻结 |
| “猛地抬头”改“快速抬头” | 不强制改写原动作力度；源描述保留，补充小表演不能削弱爆发和吃痛 |
| 每场只有一个外放峰值 | 克制文戏可用，不覆盖剧本明确要求或战斗中的多次受击 |
| 精确露齿数量、固定“几分”、通用两条负面词 | 改为按需，不当机械模板或模型能力保证 |

生成前验例：无对白的倾听段不能新增内心独白；一条原句跨两个节拍时文字顺序不变；近景不得新增看不见的脚步；只见腿却要求上身攻击时返回摄影冲突；独臂怪物受击允许有力反冲，不补回缺失肢体。这些是文本行为检查，不是已完成的模型成片测试。
