# 人物表演提示词

约10–60秒短剧本是常用输入，不是视频接口长度承诺。先读项目 `AGENTS.md`；已有确认的剧本/分镜优先。本技能采用用户提供的 [原文](references/用户原文.md)，取舍与既有资源分工见 [融合说明](references/融合说明.md)。

执行根规则及 [导演流程](../../../docs/工作流/director-workflow.md)「表情、情感与镜头表现」：默认表演丰富、有层次；上游“克制”只用于合适情境，不能把人物统一压成微弱、单一反应。

## 唯一职责与输入锁定

- 只补充既定事件触发的可见表演。保留说话人、台词逐字原文及标点、画外音归属、说话方式、时间窗、镜头/景别/运镜、动作和场景事实。不要为让模型“有表演”添加台词或新事件。
- 不新增剧本未写的起身、走动、摔物、拥抱等事件、大动作、场景、光线、音效或摄影。可细化与原动作兼容的眼神、眉眼、唇部、呼吸、肩颈、手部与姿态反应，幅度按情绪和景别决定，不一律限为微动作；不能挤掉原动作时间或占用持武器的手。
- 先想清人物此刻的意图与情感变化，再写外显表现；简洁写明情绪递进及其触发，不以长篇心理分析替代可见表现。外部事件按原文保留在对应时间，只作为反应触发，不扩写其拍法。
- 原文记录/创作说明保留用户原句。模型正文语言遵循项目及用户最新要求；若需要英文，仅翻译导演说明、保持意义和强度，台词/画外音仍逐字原文。翻译不是改剧情或改镜头的许可。
- `fight-scene-design` 决定招式、重心与攻防；`storyboard-camera` 决定摄影与可见范围；本技能只填表演层，再交摄影整合。已给完整分镜时不再要求重走补全文案确认。

## 先检查可见范围

读取当前镜头的实际画面范围，单人镜头只写可见者，双人镜头分别写说话者/听者，画外角色只保留原有声音信息。只在能读到脸的景别细写微表情；远景优先用已有姿态、呼吸和动作的整体反应，不能塞入看不见的眉眼细节。

**景别缺失不自动设成胸部近景。** 优先查已确认分镜；仍缺失时标注“可见范围待摄影确定”，先完成不依赖新增构图的表演建议。只有时间或可见性缺口实际阻塞交付、且无法由现有资料合理确定时，集中询问。不能为了让演技可见而偷偷裁掉攻击者身体。

若既有镜头只见腿，但该时段主动作是上身攻击，指出摄影冲突，交 `storyboard-camera` 在最终提示词前修正覆盖；不删掉主攻击、不宣称画外的面部/上身反应已被拍到。本技能单独受托时保留原镜头，附最短缺口说明，不擅自改镜头。

## 写作步骤

1. 提取源信息：时间窗、角色/说话人、逐字台词、镜头范围、既定动作、事件触发和伤势/疲劳/持物状态。优先沿原切镜分节拍；同镜有多次情绪转折可细分时间，不能因此新增切镜。
2. 找到反应因果：触发或内部消化 → 外显变化 → 控制/落幅 → 残留。新情绪通常叠加到上一状态，不能每切镜都恢复中性。无需机械凑齐四拍或每秒安排变化。
3. 写一小段全局表演设定：既定身体底色、持续视线/呼吸/紧张程度、伤势限制与本场基调。选择少量有效锚点，不重复角色背景故事。
4. 逐节拍按“时间 → 原有镜头/景别 → 原台词及说话方式 → 原动作/事件 → 触发与台词相位 → 可见表演 → 其余自然保持”组织。没有的字段省略；保留原信息，不填空造设定。
5. 转折处细写，平稳处自然延续：选择能被当前镜头读到的表情与肢体组合，写出发生次序、幅度和残留；不要让所有部位同时争抢注意，也不机械限制每拍只能几处变化。检查人物之间、前后节拍是否反复同一种微笑、点头或站姿，按真实情感更换表达；既定动作和正常口型持续。
6. 检查全部时间覆盖、对白与反应容量。先删重复修饰和装饰性微动作，不改台词、压掉攻击、任意延长片长或偷偷增加切镜；确实装不下则给总导演/摄影明确冲突。

## 表演强度

- 默认自然但表情丰富、情感清晰，强度随性格、关系、刺激和剧情变化。可以明显惊讶、喜悦、悲伤或愤怒，也可以收敛、掩饰和渐变；每种情绪都用具体可见表现落实，不用“几分、微微、轻轻”统一降幅。
- 复合情绪整体描述，或先后渗入；不用“上半脸悲伤、下半脸笑”给五官分配不同情绪。转折写先变化的部位和时间关系，不把眉眼嘴肩同时拉满。
- 情绪稳定时自然延续并保留倾听反应；转折处表现变化与余韵。强情绪是否克制由人物与剧情决定，“一场一个外放峰值”只作明确克制文戏的可选方法，不覆盖多次爆发、大哭、喜剧或其他表演目标。
- **微表情克制不等于动作软弱。** 不把剧本已定的猛击、快速抬头、腾跃、剧烈受击或痛呼改成小动作；力量与疼痛幅度由动作、伤势和本场基调决定。打斗的短促反冲、失衡、保护伤处与恢复可跟攻击并行，不新增双方停下来“演情绪”的空档。
- 非人角色只用其确有结构：头部朝向、口器张合、躯干张力、触须/根须反应等。没有眉眼或人类嘴唇时不套人类五官配方；断肢不能捂伤、持物或恢复。
- 不写FACS编号，不把精确露齿颗数、瞳孔尺寸或固定眨眼频率当通用要求。“下巴不成U型”“面部不变红”等负面词仅在对应风格/具体问题需要时采用，不默认给每镜追加。

## 写入前检查

按根规则及导演流程「提示词迭代审计」执行下列检查；有不符就修改，再复核受影响项及全局一致性，直到所有适用标准通过才定稿/交付/提交。“二次”不是次数上限，缺证据或需要用户决定时明确标未通过，不用建议代替修正。

- 源台词（含标点、归属、画外音和说话方式）与动作/摄影事实是否完整，语义或力度有没有被“克制”误改？
- 新增内容是否只在表演层；是否偷加对白、音效、机位、走动或改变事件时序？
- 触发先于反应，表演与“说之前/说到原句某词/话音落下”的关系明确，跨镜残留与伤势一致？
- 是否有具体的情感递进、面部与肢体变化，倾听者是否有反应；是否只贴情绪标签、整场同一种表情/姿态或被一律“微微”削弱？中文设计的这些细节是否完整进入英文提示词？
- 只写可见部位，脸部变化密度和身体结构合理；是否出现腿部构图承担上身攻击的冲突？
- 视线目标、方向、幅度和头部联动有必要时说清；其余部位自然保持，不冻结、不挤占原动作？

输出为简短全局设定＋时间节拍，不再单独制作一套竞争剧本。整合到现有 `视频提示词.md`，源事实对照放创作说明或已有分镜。生成前检查不等于成片验收；多片段做技术检查并由总导演完成全部N−1处接缝及最终文件动态验收，再供用户审整体创作，不扩为默认逐段表演/运镜/特效审计或自动重抽。
