# 红果动作簇与节奏编排

本文件的“红果”仅用于内部节奏路由。交付给即梦的提示词不得出现“红果高速”“红果式”“攻守反转”等标签，必须改写为可见动作、秒数、机位、声音和结果。

## 节奏定义

节奏由单位时间内可读的状态变化决定，不由切镜数量或形容词决定。有效变化包括：

- 威胁：未知→察觉→逼近→命中窗口；
- 距离：远距→中距→近距→接触；
- 优势：均衡→压制→反制→代价；
- 能力：未知→征兆→规则显露→克制/失效；
- 伤势：无伤→擦伤→活动受限→恶化；
- 目标：试探→破防→夺物→逃离/终结；
- 信息：不知→察觉→揭示；
- 关系：畏惧→抗衡→掌控/背叛。

换景别、变亮、粒子增多和同义重复本身不算状态变化。

## 自动路由

- 战斗、追击、斗法、召唤、变身、爆炸与破坏：连续动作密度；
- 对白压制、能力规则揭晓：均衡战斗；
- 首次召唤、觉醒、法相和死亡落幅：仪式/压迫，可降低密度但必须有不可逆阶段；
- 普通文戏：退出本节战斗指标，沿用三步骤常规节奏。

用户指定优先。节奏指标不得损害逐字台词、动作因果与可读性。

## 战斗镜号负载

一个10—15秒战斗外层镜号默认至少6个真实内部切镜，通常6—10个；复杂但仍可读的动作簇可扩展到11—12个：

- 对白压制：6—8镜；
- 近战、追击：6—10镜；
- 法术反转：6—10镜；
- 仪式、召唤、变身：6—8镜；若过程确实不可拆分，可在工作层说明原因；
- 日常剧情、生活和普通文戏：4—6镜，保持自然节奏；
- 每个内部镜头通常1.2—5秒，单镜超过6秒应拆切或明确表演原因；
- 每15秒至少3次有效状态变化；
- 每个外层镜号只保留一个最高峰值。

## 动作簇

满足以下条件时合并为同一外层镜号：

- 同一攻击目标与战斗轴线；
- 动量连续，前一招回收可直接成为下一招起势；
- 距离和场地没有跨越难以追踪的变化；
- 武器、人物和能力媒介不需重新建立；
- 特效阶段可在15秒内完成一个清楚的小型反转。

出现以下任一项时拆成新镜号：

- 优势方变化需要独立确认；
- 进入新场地、空域高度或新轴线；
- 法相、召唤物、领域或变身完成结构重组；
- 同时出现超过两个复杂高速主体；
- 台词时长与动作负载超过15秒；
- 身份、武器、接触点或空间因果开始不稳定。

拆分单位是状态变化完成点，不是每一个动作动词。

## 镜内微动作

短于1.2秒的内容嵌入合法内部镜头：

| 微节拍 | 参考范围 | 功能 |
|---|---:|---|
| 征兆/预备 | 0.2—0.8秒 | 目光、尘粒、支撑脚、武器角度 |
| 承诺动作 | 0.5—1.6秒 | 冲刺、挥击、施法进入不可随意取消状态 |
| 接触瞬态 | 0.1—0.4秒 | 人、武器、法术与目标同步 |
| 峰值强调 | 0.2—0.8秒 | 只用于改变优势的一击 |
| 受力反馈 | 0.4—1.2秒 | 身体、衣物、地面和声音回应 |
| 恢复/接口 | 0.3—1.0秒 | 回收、落地、转身并接下一招 |

这些是可调参考，不是固定帧表。重兵器、巨物、受伤和仪式可以更慢。

## 多切镜覆盖链

战斗优先让至少6个内部镜头承担不同功能；日常剧情使用4—6个内部镜头：

`空间/关系 → 攻击承诺 → 接触证据 → 能力变化 → 受力反应 → 反转/钩子`

战斗不要求机械凑满六类功能，但至少六个切镜必须产生独立信息、动作证据、接触、受力、能力阶段或恢复接口；不得连续两个内部镜头只做凝视、蓄势、环境或恢复。普通格挡不同时使用慢动作、强爆光和完整落幅；仅最高峰值享受稀缺强调。

## 五条并行时间轨

```text
人物动作：支撑→挥击→接触→恢复
对白口型：吸气→片段→重音→闭口/画外延续
能力特效：征兆→生成→传播→接触→衰减
环境反馈：衣物/尘→材质破坏→烟/碎屑遗留
摄影机：切入→镜内运动→接触前稳定→切出
```

异能＋玄幻场景可在五条时间轨之外增加两条增强轨：

```text
能量生命周期：征兆→聚集→启动→传播/附着→接触→反馈→衰减→遗留
能力绑定：身体动作→兵器/法宝媒介→法相或外显同步→环境反馈→恢复接口
```

两条增强轨必须与人物动作、接触点和唯一峰值对齐；不能用能量亮度、粒子数量或镜头旋转单独制造状态变化。

能同时发生的内容应重叠：压刀与台词、腐蚀与剑纹暗淡、听者蓄力与说话者施压、爆炸余尘与下一轮攻击、落地恢复与再次冲刺。

## 防拖沓

以下情况必须重新分簇或切镜：

- 一个内部镜头持续6秒以上却没有新状态或表演推进；
- 一句长台词全程停在同一机位；
- 连续两镜只在凝视、亮剑、蓄势或恢复；
- 同一能量状态被三个镜头重复展示；
- 等烟尘完全消散、人物完全站正或武器完全收回后才继续；
- 每个普通接触都成为慢动作高潮；
- 增加时长只为容纳重复字段。

## 防过快

快节奏仍须让观众读懂攻击者、目标点、接触/闪避、受力、恢复、新能力媒介和优势变化。若无法回答“谁打谁、有没有接触、为什么反转”，应减少一个次要动作或拆镜，不能用粒子和乱摇掩盖。
