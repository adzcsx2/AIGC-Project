# 跨切镜台词、发声与微表情

## 台词锁

- 引号内字词、顺序、归属和所在外层镜号与原文一致；
- 未经允许不改标点；停顿、重音和句尾走向写在发声说明；
- 同一时刻只让当前说话者口型清楚；传音、心声、通讯和广播分别标OS/VS/设备声；
- 无对白不虚构台词，保留呼吸、发力、环境和特效声音。

## 表演链

每句重要台词按以下顺序推演：

`场景与身体状态 → 说话动机 → 眼神/面部触发 → 呼吸与重心 → 发声参数 → 逐字台词 → 情绪落幅`

发声至少包含音量、语速、停顿、句尾语调中的两项，再加入音质、呼吸、气音、颤音、咬字或关键词重音至少一项。禁止只写“愤怒地说”“冷冷地说”。

微表情选择1—3项可见证据：眼神落点、眉心/眉尾、眼睑、瞳孔聚焦、嘴角、唇部、下颌、吞咽、鼻翼、手指、肩颈或重心。克制情绪用细小局部变化，不在每次切镜后重新瞪眼或重置表情。

## 语速与时长

- 普通对话约4.5字/秒；
- 郑重、震惊、宣告和咒语约4字/秒；
- 快速、急切约5—5.5字/秒；
- 受伤、哽咽约3—4字/秒。

另加必要吸气、停顿和反应。听不清时减少画面动作负载或增加台词承载镜，不把台词加速到失真。

## 跨切镜连续声轨

长台词先建立唯一完整台词锁，再按意义、呼吸和镜头信息切分。每段只出现一次：

```text
说话者[SYNC]：“可见口型对应的片段”（本片段需Xs；声线、语速、呼吸与上一片段连续）
说话者[OS-CONTINUE]：“切到武器/听者/环境期间继续的片段”（本片段需Xs；不中断、不重新起句）
说话者[SYNC]：“切回说话者后的片段”（本片段需Xs；从上一字自然续接）
```

规则：

- `[SYNC]`要求完整可见说话者嘴部，不被兵器、手臂或特效遮挡；
- `[OS-CONTINUE]`要求前一镜已启动同一句对白，本镜不出现竞争口型；
- 切回`[SYNC]`不能重复前面片段；
- 所有片段按内部镜头顺序拼接，必须与原始整句完全相同；
- 一句对白的音量曲线、语速基线、声线和呼吸状态跨镜连续，只有剧情触发才改变；
- 台词在第六节用声桥连接，切点优先落在自然停顿、关键词前后或听者反应点；
- 台词超过6秒时，不允许只由一个固定机位承载；每1.5—3秒至少改变一次力量、位置、能力、伤势、信息或听者反应。

## 台词与动作并行

说话者可以持续压刀、扣紧手指、调整重心或维持施法，但不要同时承担复杂旋转、快速位移和精确口型。听者用眼神、呼吸、握持、脚步或蓄力回应，不抢口型。

重音可以同步：压刀加重、护罩开裂、黑雾越刃、能力反推、伤势显露或关系易位。特效峰值不应全程遮脸；需要大爆发时优先安排在台词结束或句内决定性重音处。

## 情绪连续性记录

每个内部镜头记录的是同一情绪过程的当前阶段：

- 触发：看见威胁、受伤、听到信息；
- 上升：呼吸、握持、眉眼或声压改变；
- 峰值：关键词重音与动作/能力变化同步；
- 落幅/转化：闭口、移开视线、重心变化或下一选择。

切镜只改变观众所见，不自动改变角色心理。

## 质量检查

1. 台词片段顺序、标点和归属正确；
2. 片段拼接与原文逐字一致；
3. SYNC镜口型清楚，OS镜没有竞争张嘴；
4. 发声参数具体且跨镜不矛盾；
5. 微表情强度与景别、情绪阶段相符；
6. 长台词期间画面持续推进而非视觉停滞；
7. 台词结束、动作峰值与情绪落幅时序清楚。
