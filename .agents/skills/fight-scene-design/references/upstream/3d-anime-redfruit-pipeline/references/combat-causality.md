# 战斗因果与连续性

当剧本包含异能、能量兵器、法相、护体罡气、空间扭曲或类似玄幻特效时，同时读取 `ability-fantasy-combat.md`。该模块补充视觉层级和能量生命周期，不改变本文件的攻防主结果、受力方向、伤势连续和能力阶段约束。

## 战斗状态

内部记录双方目标、胜负条件、当前优势、优势证据、对手应对、反转触发和代价：

`优势方 → 优势证据 → 对手应对 → 反转触发 → 新优势方 → 代价/遗留`

镜头角度、特效变亮或招式名字不能自动改变优势。优势必须落在位置、距离、武器、伤势、能力、信息或目标上。

## 攻防状态机

每个主要交换锁定：

```text
攻击者起点｜支撑脚/施法媒介｜重心与轨迹｜目标点
承诺动作｜主动窗口｜接触/最近点｜命中/格挡/偏转结果
受力方向｜双方恢复姿态｜下一招接口
```

要求：

- 起势至少保留目光、脚步、武器角度、声音或环境先兆之一；
- 格挡写接触面、角度、支撑和力的去向；
- 闪避写原目标点、闪避路线和攻击落空后的去处；
- 命中同步身体、武器/法术、衣物/毛发、地面/空气和声音；
- 恢复决定下一动作，通常在受力镜尾部开始并在下一切镜完成；
- 连招必须从上一招回收自然进入下一招，禁止无意义旋转、空中停顿和无交代换边。

高速并不要求每个内部镜头都包含完整状态机；至少6个切镜共同覆盖一条完整交换，复杂动作可扩展到11—12镜，但接触或闪避同步点必须至少有一镜清楚可见。

## 能力与战斗身份

影响结果的能力、法宝、身法、阵法、召唤物和持续状态内部记录：

```text
ID｜所有者｜用途｜能量来源｜媒介｜启动姿势/口令
距离/方向/持续｜消耗/打断窗口｜命中条件｜即时结果
克制条件｜结束/遗留｜视觉签名｜声音签名｜禁止变化
```

阶段按准备→启动→释放→传播→接触→持续→打断/衰减→结束。切镜不能令能力无因跳段；消耗、冷却、伤势和法宝损坏进入下一镜。

异能增强场景额外记录：身体层表现、能力媒介、外显层/法相、能量颜色或声音身份、环境反馈、能量当前阶段和遗留。身体、媒介、外显三层至少保持两项可辨识的一致性；法相或护盾不得只因面积和亮度增加而自动改变优势。

双方除颜色外至少用两项区分：轮廓、边缘、纹样、轨迹、粒子行为、节奏或声音。去色后仍应辨认所有者。

## 多能力碰撞

记录双方阶段、碰撞位置/时刻、入射方向、强弱依据、唯一结果、能量去向、人物反馈、材质反馈、二次传播、衰减和遗留。

主结果只选一种：格挡、偏转、吸收、穿透、抵消、转化、连锁或破盾。次级火花、风压和碎片不算第二主结果。“碰撞后巨大爆炸”不能代替因果。

破盾遵循形变→裂纹→局部失效→整体崩解。净化、吸收、反弹和转化必须有媒介、窗口和代价。

## 力量、材质和伤势

尺度仅用于连续性：S0接触级、S1局部级、S2场地级、S3建筑级、S4地貌级、S5天象/领域级。能力尺度、人物受力和环境破坏可以不同，但须解释能量被何种媒介或地形吸收/导走。

材质按完好→形变/焦灼/结霜→裂纹/松动→局部断裂→整体失稳→二次坍塌推进。石、金属、玻璃、木、布、水和土不能产生同一种反应。

伤势记录部位、类型、程度、活动限制、呼吸、握力/施法稳定性、衣物/护甲和可见痕迹。腕伤影响握持，腿伤影响支撑，肩伤影响抬臂，能量灼伤影响持续施法。不得无因复原或擅自升级伤害。

## 类型路由

- 近战：支撑、距离、武器长度、轨迹、接触与回收；
- 法术/结界：媒介清楚，大招按准备、聚能、释放、接触、余波；
- 身法/传送：入口、出口、观察位置与环境反馈；
- 变身/觉醒：征兆、局部变化、结构重组、新状态稳定、余波；
- 召唤/巨物：媒介、数量、位置、尺度参照、重量和退出；
- 空战：高度、方向、相对位置、地面/云层参照和惯性；
- 群战：每拍一个主交互对，其他角色执行辅助任务；
- 爆炸/坍塌：爆点、压力方向、碎片来源、掩体、阈值和落点。

## 战斗检查

去掉特效后仍须读懂谁攻击谁、目标、接触/闪避、受力和恢复；优势变化有明确触发；能力阶段、武器、伤势、站位和环境损坏跨切镜连续；快节奏来自动作簇与并行，而不是漏过程。
