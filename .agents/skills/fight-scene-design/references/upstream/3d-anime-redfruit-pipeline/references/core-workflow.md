# 核心工作流与用户可见契约

## 输入边界

开始前读取：转化模式、平台/模型、画幅、单段时长、角色资产、视觉类型、音频能力、年龄分级、旁白、上一镜号和首尾帧。缺失普通制作细节可做克制判断并标明；不得擅自补充会改变人物、世界观、能力、胜负或平台可执行性的事实。

无损模式保留事件、对白字词与顺序、动作过程和结果。影视化改编只有用户明确允许时启用，并在交付前说明实质变化。

## 场景自动路由

- 战斗、追击、斗法、召唤、变身、爆炸、坍塌：连续动作密度，原生多镜至少6切，通常6—10切，复杂但仍可读时可到11—12切；
- 高频争执或危机场景：4—6切，按信息和情绪变化决定；
- 普通文戏、生活、情感、解释性段落：4—6切，保持自然节奏，不强制高密度动作；
- 用户明确单镜到底：退出本Skill，改用相应单镜工作流。

在第一节【大场景】末尾加入可解析元数据，不新增字段：

```text
场景模式：战斗；节奏：连续动作密度；状态变化：均衡→沈夜持续下压→黑雾越过剑刃→林烬左脚前踏蓄力。
```

文戏使用“场景模式：文戏；节奏：自然对白节奏”。

## 内部工作稿

内部完成七大节：

1. 场景与连续性；
2. 本镜叙事参数：节奏、台词锁、动作映射、时间与峰值；
3. 镜头设计总图：约束包、覆盖图、机位、光源、切点与技巧筛选；
4. 内部镜头；
5. 生成参数；
6. 剪辑衔接总表；
7. 特效对照表。

第二、三节参与回写但不向用户显示。第二步改变台词时间后必须回写内部时长；第三步改变镜头覆盖后必须重新核对动作、台词和总时长。

## 用户可见标题与章节

```text
【镜号006】·寂灭宣言·单段整合版（约15秒·6内部镜头）

一、场景与连续性
四、内部镜头
五、生成参数
六、剪辑衔接总表
七、特效对照表
```

用户可见分镜禁止使用Markdown井号标题，章节只能按上述顺序出现。

## 第一节固定字段

```text
【大场景】
地点、阶段、本镜改变的故事/战斗状态；末尾写场景模式、可见节奏描述和状态变化链。不要写平台或流派标签。

【小场景】
具体区域、画左/画右/中央、高低差、入口出口和危险区。

【时间／天气】
时间、天气、风、空气、可见度与基础光线。

【群像分层】
前中后景、主动作、次动作、环境动作和其他在场角色任务。

【角色账本】
只列本镜出现的角色名字，不写状态、动机、眼神、眉眼、嘴部、呼吸、重心或情绪变化。

【角色声音账本｜最多3人】
只列本镜发声角色名字；具体音量、语速、停顿、呼吸、重音和口型写入对应内部镜头。

【人物专属道具锚定】
武器、法宝和关键道具的所有者、握持、位置、充能与损坏。

【轴线与运动方向】
画面方向、战斗/对话轴、攻击、追逐、飞行和出入画方向。

【空间位置与角色站位】
相对距离、朝向、高度层与结束位置。

【首帧参考】
继承上一镜尾态。

【尾帧参考】
本镜结果、遗留和下一镜动作接口。

镜号末尾追加：

【角色／武器／伤势】
汇总角色、武器持有和伤势遗留。

【光线／声音】
汇总可听见的环境声、对白声桥和特效声，以及光线变化。

【节奏功能与状态变化】
只写可见动作顺序和结果，例如“张十三踏地→刀爪接触→爪背焦黑→爬行者后退”；不要写“红果高速”“攻守反转”“压迫感”等平台或情绪标签。
```

## 第四节内部镜头

战斗镜号默认至少6个内部镜头，通常6—10个，复杂但仍可读时可扩展到11—12个；日常剧情保持4—6个内部镜头。每个镜头是真实独立机位。固定格式：

```text
【内部镜头N｜Xs｜名称】
机位：<物理落点>。景别：<景别>｜高度角度：<高度与角度>｜焦段：<焦段>。
构图：<画左/画右、前中后景、主体、目标点和最高可读区>。
运动：<本切镜内的运动牵引、起点、方向、速度和停止点；无理由则固定>。
画面：<本镜承担的动作过程、接触/闪避、受力、恢复与下一接口>。
台词与口型：无 / 角色[SYNC]：“本镜实际片段”（连续声线与表演；本片段需Xs） / 角色[OS-CONTINUE]：“本镜实际片段”（承接上一切镜声轨；本片段需Xs）。
【特效阶段】：<本镜触发→生成→传播→接触/作用→反馈→衰减→遗留>。
```

规则：

- 内部镜头默认不少于1.2秒；更短动作作为镜内微节拍；
- 所有内部时长相加必须等于标题总时长；
- `[OS-CONTINUE]`只用于前一镜已启动且本镜不中断的同一句对白；
- 切回说话者时恢复 `[SYNC]`，不能重新念已说片段；
- 相邻内部镜头的机位、景别、焦段、高度和叙事功能不能全部相同；
- 内部镜头不写硬切、转场或拆分命令，统一放到第六节。

## 第五节生成参数

只允许：

```text
五、生成参数

比例：16:9

【风格词缀】
必须以“4K画质，电影级3D游戏CG概念风格”开头；随后写上一镜可继承的角色外观、道具、站位和光线锚点、主要动作、轴线、光线与连续声轨。用具体动作和镜头替代平台、流派标签和切镜数量，不重复第四节全文。平台模式、原生多镜字样和切镜数量不写入第五节。只有目标平台明确支持时才追加英文连续性短语。

【固定禁止项】
no subtitles, no watermark, no logo, no random text, no background music generated

【负面提示词】
选择10—20条本镜高风险失败模式；有台词时包含对应片段或全句时长限制。
```

第五节不写平台模式、原生多镜字样或切镜数量；禁止新增“完整提示词”“即梦直接粘贴提示词”等重复区块。

## 第六节剪辑与拆分回退

固定字段：

```text
【镜头间衔接】
镜头1尾帧（切点3.3秒）→镜头2首帧：动作/视线/形状/特效匹配；声桥：[SYNC]→[OS-CONTINUE]。
...
拆分回退：若原生多镜失败，按镜头1—N分别生成；每镜沿用本节切点、方向、首尾状态与连续声轨，按原顺序剪辑。

【首帧参考】
与第一节一致。

【尾帧参考】
与第一节一致。

【验证重点】
检查切点、轴线、接触、受力、声桥、武器、伤势和特效阶段。
```

每个累计内部时长都必须在【镜头间衔接】中出现为切点。拆分回退不新增另一套提示词。

## 第七节特效对照表

```text
【特效资产与阶段总链】
触发→生成→传播→接触→反馈→衰减→遗留。唯一峰值：内部镜头N的<事件>。

| 内部镜头 | 时长 | 主层 | 反应层 | 遗留层 |
|---|---:|---|---|---|
| 镜头N 名称 | Xs | 决定结果的能力/碰撞 | 风压、火花、衣物、材质 | 烟、裂纹、焦痕、残阵、伤势 |
```

表格必须逐内部镜头对应；同一外层镜号只有一个“唯一峰值”。

## 输出前检查

1. 固定事实、动作过程、台词、胜负和结果无损；
2. 场景路由正确，文戏没有被强制切成战斗密度；
3. 战斗至少为6个真实切镜，通常6—10个，复杂但仍可读时可到11—12个；日常剧情为4—6个真实切镜，时长合计不超过15秒；
4. 台词片段拼接完整，SYNC/OS连续且不重复；
5. 相邻机位真正变化但轴线和方向连续；
6. 每个动作含目标、接触/闪避、受力和恢复；
7. 每个特效含完整因果并只有一个峰值；
8. 第六节含全部真实切点和拆分回退；
9. 第五节只含允许字段；
10. 用户可见章节严格为一、四、五、六、七。
