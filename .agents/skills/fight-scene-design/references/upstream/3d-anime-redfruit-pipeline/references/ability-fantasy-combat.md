# 异能＋玄幻战斗增强模块

本模块只在原剧本明确出现身体强化、元素/能量操控、念力、空间能力、法相、内力场、护体罡气、能量兵器或类似玄幻特效时启用。它是 `redfruit-pacing.md`、`combat-causality.md` 和 `master-shots-multicut.md` 的增强层，不覆盖用户原设定、动作因果、唯一峰值、轴线连续和15秒上限。

## 1. 能力视觉层级

把能力拆成三层，并让三层保持同一来源：

1. **身体层**：能量脉络、发丝与衣袂受场、重心偏移、皮肤或护甲上的能量外壳。
2. **媒介层**：拳脚、兵器、法宝或施法动作承载能量；媒介必须有明确所有者、起势、方向和消耗。
3. **外显层**：法相、内力场、护体罡气、空间扭曲、气浪、粒子或环境染色。

身体、媒介和外显层必须在颜色、轮廓、粒子行为、声音或运动轨迹中至少保持两项一致。法相不是贴在背景上的平面贴图：需要有体积、遮挡、投影、重量和移动造成的气流或材质反馈。

如果用户没有明确指定能力形态，不新增法相、空间裂纹、巨大能量武器或能量兽首；优先使用原文已有的身体、兵器和环境反馈。

## 2. 能量生命周期

每种重要能力都建立一条可观察的生命周期：

`征兆→聚集→启动→传播/附着→释放→接触→反馈→衰减→遗留`

- 能量不能在切镜之间无因凭空出现或消失；切镜只改变观众所见，不跳过关键阶段。
- 兵器蓄力优先写成能量从刃根、柄部或核心向目标端逐段汇聚，再进入挥击或释放。
- 法相按虚影→轮廓成形→局部凝实→同步动作→受击/反馈→消散处理；不因镜头仰拍或亮度增加自动获得优势。
- 空间裂纹、能量脉络和护盾裂纹必须有触发源、传播方向、作用对象和遗留状态；禁止把纹理写成无来源装饰。
- 一个外层镜号只设一个最高峰值。普通征兆、火花、粒子和小幅涟漪不能与主峰值同时升级为第二个高潮。

## 3. 能量兵器四层结构

带能力的拳脚或兵器按需要调用四层：

1. **本体核心层**：金属、石、骨或其他材质真实可见，保留握持、重量和受力。
2. **包裹层**：贴附在拳面、刃面、枪尖或护臂上的火焰、雷电、冰晶、气流或能量外壳。
3. **拖尾层**：挥击产生的弧形光带、粒子尾迹、残影或压力线；拖尾必须跟随真实轨迹，不替代轨迹本身。
4. **环境反馈层**：空气扭曲、地面裂痕、碎屑、衣发、尘雾、材质凹陷、金属共振或光色染场。

普通动作至少读清本体和包裹层；蓄力、挥击、命中或反转镜头至少补出拖尾或环境反馈中的一项；重击峰值尽量完成四层闭合。特效层不能遮挡目标点、接触面、受力方向或人物身份。

## 4. 法相与角色绑定

法相只在原文明确存在或用户明确要求时启用。启用后遵循：

- 角色与法相共享同一动作意图：角色出拳，法相同步出拳；角色受击，法相在同一受力方向出现晃动、能量飞溅或局部失稳。
- 法相的大小、距离和机位必须服务于空间读法；大全景展示体积和遮挡，中近景展示绑定关系，接触特写展示能量作用。
- 法相移动时带动空气、尘雾、雨水或碎石；法相落地或挥击时必须有重量参照。
- 法相不能只作为背景装饰连续三个镜头重复出现；每次出现必须新增体积、动作、受击、能力阶段或关系信息。
- 法相合击的主结果仍按“格挡、偏转、吸收、穿透、抵消、转化、连锁、破盾”之一确定，冲击波和粒子只写反应层。

## 5. 颜色、光线与声音身份

- 对立能力优先使用可区分的颜色、边缘行为、粒子节奏或声音；颜色不是唯一身份依据。
- 能力升级可通过亮度、饱和度、密度、速度或覆盖范围递进，但不能只写“更强、更亮”。
- 环境光应被能力实际染色：能量光照亮面部、法相投下色影、兵器光改变近地尘雾；光源方向与角色站位保持连续。
- 能量凝聚使用低频共振与高频电流/火焰/冰裂声；兵器蓄力使用从弱到强的金属共鸣；命中使用一次明确的重低音、材质声和人物受力声。
- “抽声”只用于唯一峰值或重要心理落差：短暂压低环境声，保留心跳、耳鸣或呼吸，随后让主碰撞声落下；不得每次接触都抽声。

## 6. 速度曲线与切镜接口

异能＋玄幻打斗可采用“快—稳—慢”三段曲线，但必须绑定动作证据：

- **快**：承诺动作、起步、瞬步、蓄势完成或能量从媒介向目标端汇聚。
- **稳**：飞行、接近、绕身或追击，让观众读清攻击路线、目标点和空间关系。
- **慢**：唯一峰值的接触、破盾、反转、重大受击或不可逆能力变化；展示形变、材质反馈和角色恢复接口。

近身缠斗可使用“短—短—整”的覆盖结构：两个短促的拳脚/兵器/擦身信息镜，接一个完成连招、摔投、法相碰撞或恢复接口的较长镜头。内部镜头仍默认不少于1.2秒，短动作作为镜内微节拍，不把0.5秒动作强行独立成非法镜头。

当连续近景无法读清双方位置、法相体积或攻击方向时，插入全景或高位俯拍重新建立空间；不得仅因回合数量机械切全景。360°环绕只在法相体积、合击轨迹或角色与法相绑定关系需要多角度展示时使用，且必须保持轴线和目标点可回放验证。

## 7. 输出与禁用项

在用户可见提示词中把“大片感、能量暴走、压迫感、终极放大”等抽象标签改写为可观察的镜头、秒数、光线、声音、材质、速度和位置。

如果项目世界观明确禁止符文、法阵或咒文图案，在本镜【固定禁止项】或【负面提示词】中写明；否则不要把“无符文”推断为所有项目的通用限制。

始终保留：动作起势、目标点、接触/闪避、受力、恢复、能力媒介、环境反馈、唯一峰值和下一镜接口。特效不能替代胜负、伤势或优势变化。
