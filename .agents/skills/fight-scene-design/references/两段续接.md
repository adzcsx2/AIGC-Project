# 多段打斗与既有片段续接

默认流程见 [多片段制作](../../../../docs/工作流/multi-segment-video.md)：先审计模型段内切镜、首尾图分段或混合方案，决定段数与时长，Codex先做N−1张内部边界图及必要端点，用户审图后直接生成各段，技术检查后合成给用户审视频。不再固定15秒＋15秒，不默认逐段抽帧审片或等待实际尾帧。

边界图保留双方位置、朝向、动作相位、左右兵器、断臂/伤口、环境损坏、机位与光照。后段升级来自攻防与因果，不只增加粒子；伤势与死亡不能切镜后恢复。首尾图可达性、动作启动、追击距离和终局时间在生成前审计。

## 仅在任务确需真实输出时采用串行续拍

用户明确沿既有视频接拍，或无法预定边界、必须依赖实际输出时，说明原因后采用真实尾态。提取实际末帧并按需查看末尾动作，记录方向、速度、接触/分离与伤势；不能把原计划当作已生成结果。用户接受有缺陷的首段不等于该缺陷已修复。

按实时接口核对首尾帧、参考图、视频输入。`ref_image_0`是普通参考，不保证严格首帧；必填终点图不能省略或用重复起点假造。保留原片、配置、任务ID与中文归档。

拼接遵循[多片段制作](../../../../docs/工作流/multi-segment-video.md)的接缝处理与验收：全部N−1处都检查源段两侧、真实合成接缝及最终处理版，并正常速度动态复核；格式、时间基、音轨、时长与可解码检查不能替代运动连续性验收。先修接缝并同步音轨，再按当前目标帧率处理完整成片（默认60fps）并复查；不默认叠化高速兵器或全片加速。技术及全部接缝检查通过后交付完整视频给用户审片，指定段重做并获认可后替换重合成；不自动付费重抽。
