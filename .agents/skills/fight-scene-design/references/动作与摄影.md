# 动作与摄影的项目适配

融合武指的招式/重心方法与红果流程的状态变化、因果和机位覆盖。具体用户要求优先，不套固定招式数或切镜数。

## 从一个想法到动作链

用户已明确普通打斗默认“麻利、迅速、有力量”。起手紧凑，支撑到躯干再到兵器传力；
攻击快速经过有效距离，接触产生真实冲量，回收直接进入反击。不要提前长时间举臂等招、慢慢挥到对手身上，
不要接触后双方纹丝不动，或每次回合后重新站正。去掉空档而保留短促吃痛与失衡，不能把受击反应也删掉。
局部速度强调只服务关键接触；正常动作大部分时间连续执行，不能让整个战斗像慢放。
检查成片时标出无效停顿和重复慢挥的具体区间，不能因为提示词写了速度就标为通过。

## 防回合制：动作重叠与距离循环

防守者偏导来刃时，另一侧兵器已经抢入；受击者仍在滑退，追击已经开始；闪避/落地/制动就是反击的起手。
不能每一招都完整展示“举起—慢挥—站正—换人”。保留因果不等于把所有阶段串成互相等待的单独动作。

为当前战斗设计近远距离变化：冲入→近身压迫→受力分离或主动脱离→追击→再次逼近。
不是机械规定每场都有同一套路；远程角色遵守远距战斗边界，原片复刻保留原调度。
距离拉开时至少仍有移动、追击、飞行威胁或下一动作准备；不能两人原地等镜头拍完。
空间感写具体：前景掠过的兵器/身体边缘，中间可见地面走廊，远处正在逼近的对手，纹理和地标的视差。
不得用“空间感强”代替这些关系；观察原片只能估相对距离，设计目标中的米数不能宣称是实测值。

## 只给有硬反馈的重击时停

用户2026-11-09进一步限定：**轻击不需要时停；重击且有硬打击感才允许。** 这是对早先“关键接触/险避可以骤慢”的收紧，不能再沿用旧例外。

- 先判断真实发力、接触和后果。重击需拍到实体接触，随后有明确的躯干压缩/反冲、支撑失衡或材料压裂/破碎；大特效、大音效、机震不能单独证明重击。
- 轻踢盾、借盾蹬离、试探、擦击、轻触格挡、拨挡、勾带、闪避、落脚和回收全速经过。它们不能因为被写成“关键拍”就时停；本次约5秒的腿顶盾明确归为禁停动作。
- 为当前片段列重击白名单。每项写“快速进入→具体接触面→瞬间受力压缩→短强调→立即全速反冲/碎裂→下一动作”；白名单之外没有时停或骤慢。未给出可信硬反馈就删除该处时停，不能为保住时停而凭空加强攻击或改剧情。
- 重击可多次强调，但按重量与容量分层。可从约0.08–0.16秒的极短设计起步；这只是屏幕时间意图，不是模型精确帧数保证，不把普通打击拖成半秒至一秒停住。仅在用户另行要求更长展示时调整。
- 时停只落在重击接触/结构失效，保持扭力与对手受力，碎屑、衣膜或镜头可微动；不能提前停在举腿、悬空、举臂或站正。回速紧接反冲与攻防，不能再加一拍等待。
- 内部衔接前后不安排时停来“对齐”静图。边界须落在连续运动中；如重击峰值恰好落在切口，先把切口移到回速后的承接相位。具体分段方法见 [多片段衔接](../../../../docs/工作流/multi-segment-video.md)。

原片复刻保留源片已明确的速度曲线；原创采用本条。声音瞬态、材料变化与身体冲量围绕同一接触事件同步。
速度的感受来自距离、动作重叠和快慢反差，不能只写匀速“更快”，不能靠全片后期倍速解决。

先用一句话写清本段发生什么变化，例如“甲近身逼退乙，乙利用低位攻击夺回距离，甲越过扫击接重击”。
这只是编排层；生成正文必须展开成可见动作。确定角色可动关节、支撑、兵器长度和活动范围后再编排。

| 记录项 | 需要明确的内容 |
|---|---|
| 攻击 | 发力关节、支撑点、起点、弧线/直线、目标部位 |
| 格挡 | 哪一侧的哪一接触面、角度、支撑、力传向哪里 |
| 闪避 | 原目标点、实际避让路线、失手攻击的落点 |
| 命中 | 接触同步、躯干受力、支撑位移、疼痛、材质变化 |
| 恢复 | 落地/回收/转身如何成为下一招的起始姿态 |
| 连续状态 | 武器左右、损坏、伤口、插入物、位置、光源、环境损坏 |

连续猛攻可以有短促受力迟滞，但不要让双方同时长时间等烟散或站正。巨物靠根基推移、重心与材质反应体现重量；
轻敏角色靠蹬地、收腿避让、落地再加速体现敏捷。动作密度按模型可读性调整，不规定每秒必须打几拳。
多样性来自攻防任务的变化：横纵线路、上下层位、诱导/偏转/抢入/破防/脱离；重复换动词不构成新招。
相邻主要交换若只有左右横砍、同站位复位，需说明重复的战术作用与逐次变化，否则改为能从上一出态到达的不同攻防。绚丽招式须有目标、支撑、落点与对手应对，不让巨物或伤员套不符合结构的旋转动作。

## 摄影与动作一起设计

先定世界中的轴线、地标、双方距离和运动走廊。机位至少回答“跟谁、看到什么新信息、在何时稳定或切出”。

- 中远景侧向跟移：看清双方完整支撑、距离缩短与完整交换，保留兵器挥动余量。
- 低位追随：突出位移、根须或脚步反应；低机位不等于腿部裁切。局部镜须指定抬镜/拉开/切回的动作触发，在下一次上身攻击启动前完成，拍清肩躯干、执行手/兵器与目标接触。
- 中景斜侧：展示兵器接触面、胸肩反冲与下一招回收；避免过近导致双方身份不可辨。
- 高位斜俯：用于重建落点或冲击环与场地关系，有明确目的再用。
- 环绕/越肩：用于视点转移和威胁揭示；不能连续转圈掩盖空间断裂。

接触前压低摄影机加速度，接触后一次短促震动并迅速稳定；浅景深和运动模糊不得吞掉接触面。
切点落在承诺挥击、接触后受力、遮挡或落地，下一镜从同一动作相位继续。越轴需可见过渡或中性机位。
机位数量与时长由本段内容决定；同一符合所选API时长范围的生成请求内可以多机位，不等于分别提交多个短片。

## 节奏与声音并行

让可见发力、呼吸、特效积累、身体恢复和镜头跟随重叠进行。声音遵循 `docs/工作流/music-postproduction.md`：视频默认仅已有对白、无音乐，无对白默认静音；非语言发声、材质声和环境声仅按明确要求加入，原片明确保声要求优先。非语言声不触发人物说话音色配置。
对白按实际可说时长分配；逐字核对所有源台词、说话人、顺序和标点，不替怪物加人类对白。已明确要求音效时，普通接触可给短脆瞬态与局部材料声，最高峰值再加更大的环境反馈。
已要求的环境声跨镜保持连续，音效来源与接触时刻对应。输出音轨存在不等于声音已经对点，必须实际试听或明确未试听；具体审片证据按 `docs/工作流/multi-segment-video.md` 留存。

## 来源覆盖与例外

原始 v4 七段格式、强制六切、每镜最低1.2秒、固定4K开头和拆分回退只适用于原作者专用模板，
本项目不以这些规则判定好坏。保留状态变化、完整因果、声音连续、镜头信息增量和跨镜遗留的方法。
固定结尾对峙不适合用户要求的持续猛攻；固定慢动作比例也不适用于所有片段。
原文提到的 `master-shots-orchestrator` 未随资料提供，不假装已读取其52技巧矩阵；当前独立方法已经可用。
