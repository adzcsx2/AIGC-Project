# 高密度连续打斗：项目导演合同

适用于原创连续打斗、参考图驱动的攻防、武器/徒手/异能/巨物战及动作不足的改稿。
本合同吸收 high-density-fight-prompt 的资产约束、载体适配、状态接力和导演稿编译方法，
由现有 `fight-scene-design` 执行，摄影交 `storyboard-camera`；不增加另一套导演入口。
来源固定版本、原文和取舍见 [融合审计](../../../../docs/维护记录/技能审计-高密度打斗融合.md)。
原片动作复刻不重编；局部改稿只应用有关条目。以下是生成前的设计合同，不代表视频结果已达标。

## 1. 先锁定事实，再设计角色为什么这样打

读取当前作品已确认文案和实际参考。优先级为：本次明确要求 → 当前确认事实与所选图中可信的可见结构 → 已确认战斗习惯 → 必要的动作衔接 → 其他创意。
用户要求变更装备、断臂或烧毁时，旧干净母图不能把新状态覆盖掉；图文真正矛盾且影响执行时先指出。
未知身份使用稳定的外观称呼，不由职业名自动补门派、武器或超能力。

将双方事实记录在现有剧本/分镜中，至少包含：

- 目标与行为差异：为什么逼近、为什么后撤、怎样取胜，面对风险倾向硬压还是避让；没有性格设定时仅作动作层面的最小补全。
- 身体与运动：肢体数量、关节、支撑方式、可活动范围、体量、移动/飞行条件、当前伤势限制。
- 武器与能力：左右归属、数量、尺寸与材质、连接或持握、作用距离、能量来源、启动方式及禁用项。
- 空间与终局：开场位置/朝向/距离、高度与支撑面、可用路线和危险区、指定结果/时间点、败者落点或承接下段的状态。

每张图明确控制范围：角色图控制身份和实际装备，场景图控制空间与光照，动作起点图控制起始姿态/接触/支撑关系。
完整首尾图还控制对应边界状态；角色板重复视角不增加人数，文字、边框、装饰巨像不变成战斗物体。
身份图中的站姿、背景和海报构图不冻结后续摄影。严格首尾帧入口仍须满足真实端点约束，不能借“自由运镜”忽略尾图。

只有一个角色而对手未定时，可以在待确认草案中用“对手待定”说明攻防需求；不能直接造一个现成轮廓对手投入制作。
新增角色、决定胜负、引入能力或改变结局仍按项目确认规则处理；未就绪的图不标ready。

## 2. 依身体与装备选择动作，不把所有角色写成同一套剑法

以各方当前主要攻击手段组织动作，可以衔接已有的副手段；不得为丰富度临时长出武器或第三套能力。

| 当前载体 | 编排重点 | 必须读到的受力与约束 |
|---|---|---|
| 刃器 | 尖端/刃线威胁、拨开后切入、压刃转线、刺击回收 | 接触面与偏转方向清楚，切口沿实际刃路；不能每招都是左右横扫 |
| 长柄 | 利用距离封线，回收转向，贴近后换柄端或身体应对 | 长度、杆身惯性、回收空间和近身弱点真实存在 |
| 锤/钝器 | 压、撞、砸与惯性续击，落空后如何恢复支撑 | 凹陷、塌裂、震退符合重量；不能突然像轻剑无惯性变向 |
| 徒手 | 让开攻击线、控臂/关节、贴入、肘膝或摔投 | 双手无武器；对锋刃用避让、控制非刃部或地形，不默认裸手接刃 |
| 远程武器 | 发射、弹道、规避/遮挡、换位与再瞄准 | 投射物脱离武器，经过真实距离；既定远程对决不擅改贴脸战 |
| 已确认异能 | 动作驱动局部强化、偏导、束缚或环境传播 | 来源、路线、目标、接触与残留完整；双方魔法可远程交锋，不强制拉近 |
| 有翼/其他可飞主体 | 以真实升力/推进实现升空、转向、俯冲与制动 | 先交代起飞过程，再读到高度、转弯范围和滞空条件 |
| 多足/无腿/根基巨物 | 根据足、爪、尾、腹部或根盘建立支撑、扑撞与转体 | 不套不存在的拳脚；断臂不再出招，沉重体量有重心与回收代价 |
| 机械/载具 | 用已见轮组、关节、推进器、机械臂或炮口行动 | 发力来自可用结构，装甲、传动与制动有反馈，不暗加功能 |

再校验对阵关系：武器长短和重量决定谁抢什么距离；徒手防守针对实际锋线；能力防御说清接触位置与代价。
双方徒手不套金属兵器声，重型对轻型不复制同样腾转路线。反击应利用上一招造成的重心、视野、距离或装备漏洞。
角色选择必须受累计损伤影响：支撑受损、握持减弱或缺肢要改变招式、速度和防守，不仅在外观上加伤口。

## 3. 密度来自不断改变局势的完整交换

每次主要攻防/优势转换按以下关系展开，动作可以重叠发生：

**意图与支撑 → 短促启动/加速 → 具体攻击线 → 对手同时应对 → 接触或失手 → 受力/变形 → 沿力线位移 → 留下的新条件 → 逼出下一招。**

不必给每一下轻击都添一次爆炸或建筑坍塌。连续同线路的小连击可共用一组反馈，但关键命中、落空、变线和逆转必须交代结果。
格挡改变武器与身体的去向，落空保留惯性，滑退尚未结束时追击已开始；上一招的回收本身就是下一招的起手。
重复攻击只有在持续压垮防守、逼到边缘或诱出特定应对时才成立，并写出逐次变化。

环境参与须有用途：当场景和授权允许破坏时，至少让一处主要后果实际改变后续通路、掩体、支撑或优势。
例如倒下的结构封住退路，使对方改向，从而制造新攻击角度；不能只是每镜换一批碎石。
空旷或不可破坏场景不强加坍塌，使用既有边界、高差、摩擦或可用路线产生同等战术作用。
破坏方向由接触决定，撞击从受力处扩散，碎屑和衣料有延迟；夸张魔法可扩大规模，但核心攻击和应对仍能读懂。

## 4. 状态接力与时间容量

先按用户总长、已确认情节、实际入口和衔接图决定生成段；再安排段内节拍与镜头。节拍数不是切镜数，更不是API任务数。
约15秒、且内容适合的完整交锋可以用以下五阶段作起点，时间窗可移动：

| 参考时间窗 | 状态任务 | 摄影要解决的信息 |
|---|---|---|
| 0–3秒 | 直接进入有效威胁，完成首轮攻防，建立攻击差异 | 看清谁从哪里逼近、首次接触面和退路 |
| 3–6秒 | 承接余势换线/换高度，出现有效命中或显著失衡 | 说明位移怎样发生、落向哪里，不能切镜瞬移 |
| 6–10秒 | 技术交换改变优势，利用前次动作的漏洞反制 | 拍清支撑、控线、失衡与反击的因果 |
| 10–13秒 | 用追击/封路逼出改向、脱离或新的角度 | 展示距离闭合及环境后果如何改变路线 |
| 13–15秒 | 已指定终局则交代决定性结果，否则承接下一段 | 关键命中、败者状态/落点或进行中的退出都可读 |

不固定开场三条攻击线，不强塞全部招式；巨物重量、时停、追击路程和死亡过程都占用真实屏幕时长。
不超过10秒时可压为“即时交锋—接触变线—追击逆转—结果或继续运动”的四阶段，而不是加速塞完五段。
其他时长按内容增减；用户未定长度时提出适合本场的长度和理由，不从上游自动固定15秒。

需要明确终结时，优先安排“诱出可预测应对 → 利用已形成的破绽 → 从成立的方向决定性命中”。这是因果结构，不是必须三次挥击。
终招只能用现有身体/能力，受击、失去支撑、燃烧/崩解或其他指定结果须留够时间；时间不足先删中段冗余，不把结果藏在爆闪后。
没指定胜负不自行判死；中间段不为了15秒模板先把人打死又复活。结尾余势和环境动态延续，除非用户明确要定格或静态收束。

每次阶段或切镜交接核对：**世界位置、朝向、速度方向、高度/支撑、装备、伤势/优势、环境余波**。
变化要有过程，不把“任选四项继承”当允许丢弃断臂或武器的理由。切镜改变观察点，不替代距离闭合。
把边界图的入态/出态、运动方向与尚未完成的攻击交给摄影和资产环节；沿已有视频续拍时以实际尾态为准。

## 5. 本项目的快动作＋命中时停

只有实体重击且拍得到明确反冲、失衡或材料压裂等硬反馈，才使用**快速攻击—接触点极短时停或骤慢—骤然回速**；这是用户2026-11-09进一步收紧的门槛。每段列重击白名单，不给每次命中分配时停。
在屏幕时间里给关键接触分配短强调，保持压缩、扭力和痛感，之后沿力线震退、破碎并立即续招。
轻踢盾、蹬盾借力、轻击、擦击、拨挡、勾带、闪避、回收与内部衔接全速通过，禁止时停；主要重击可多次强调，但长短和力度有层次。摄影、碎屑或衣料可继续微动，不能以微动掩盖身体近一秒停住。
不把“高密度、连续、不回合制”理解为禁止命中时停，也不把“全程连打”自动变成全程匀速。
只有本次明确要求“禁用时停/慢动作、速度不归零”等严格限制时，才改用全速接触、攻击频率和机位速度组织节奏。
保留必要吃痛与受力，去掉的是等待与摆姿；未授权的新时停超能力不能与摄影上的时间强调混为一谈。
用屏幕时间检查动作容量，不声称文字能保证精确帧数或某条速度曲线已经实现。方法详见 [动作与摄影](动作与摄影.md)。

## 6. 摄影、声音与同一版导演稿

每镜一个主要信息任务和主运镜：启动事件、跟随主体、相对路径/速度、焦点与落点明确。
轻震、倾斜和重新捕捉属于接触反馈，不能取代摄影设计。拍清实际支撑、攻击执行端、接触和必要反应；上身出招时不能继续只拍腿。
命中前稳定读到攻击线，时停保持同一受力相位，回速后接住角色位移；夸张特效在路径和核心接触附近仍留可读窗口。

声音遵循 `docs/工作流/music-postproduction.md`：视频默认仅已有对白、无音乐，无对白默认静音。只有明确要求音效时，才按启动/移动、破风、接触、吃痛、结构反馈、落地/追击设计因果与材料声；非语言发声不触发人物说话音色配置。
原有对白、字幕与明确保声要求保留；不会仅因“高密度”给徒手加剑鸣或怪物加人类对白。后期配乐意图单独登记，不编入视频生成正文；已要求的画外环境声不因“动作有源”被删除。

先交中文补全草案确认，再由摄影定稿镜头表，最后编译英文模型正文。沿用项目现有文档，不增设相互竞争的母稿。
中文导演说明与英文正文逐项对齐人物、资产、能力、事件、镜头数/顺序/切点、伤势、速度强调、声音、终局和端点。
编译不能偷偷加镜、减掉反击、改胜负或恢复断臂；需要改就先回到相应创作阶段，实质改动按原确认规则处理。
格式由实际入口决定：适用的H3参考生成可用现有六段资料；titim主体替换与真正首尾帧入口不强套Ref2VA模板。
不添加上游专用`BUNNY`、LoRA触发词、未安装的`h3-prompt-writing`依赖或虚构视频/音频标签。API输入以autodl校验为准。

## 7. 交付前二次审计

在既有运镜审计中记录以下结论，不另建一套生产状态：

1. 资产来源与身体/兵器适配成立，新增假设已确认，参考图没有控制到错误范围。
2. 主要交换能解释攻击线、防守针对性、受力去向和下一招；角色行为受目标与伤势限制。
3. 环境结果实际改变路线或优势；不适用破坏时理由和替代空间关系明确。
4. 相邻状态、距离闭合、伤势与装备完整；时长容纳时停、反击和指定终局。
5. 摄影覆盖关键部位，切点由动作触发，特效和声音没有替代实体攻击。
6. 中文导演说明与英文执行正文对齐，模型格式/媒体槽位真实，已选首尾图可衔接。

发现问题先改产生问题的动作与状态，再同步摄影和提示词；不要只追加“流畅、震撼、保持一致”。
此检查用于生成前。多片段仍按项目规则技术检查后合成交用户审片，反馈不自动触发付费重抽。
