# 电影级创作与生成决策前检查清单

写剧本前读取以建立创作基准；生成提醒之前再次逐项应用于最终方案。
适用性按当前作品判断，每项保留具体设计、证据或不适用理由；不能只打“电影感”勾。
本表是生成前的设计检查，实际效果仍须按项目交付规则和用户审片确认。

| 维度 | 写剧本与方案时考虑 | 总审计核对的具体证据 |
|---|---|---|
| 新角色三视图与实际身份输入 | 识别人类、动物及其他新角色；每个先有合格独立三视图，再制作含角色场景图，并将三视图给下游API | 按人物流程核对人物ID、板的实际文件/哈希/验收依据、制作先后及真实槽位映射；不能只有场景临时角色、清单路径或prompt提及。仅正面特写/正面全身无头/背面全身，动物按原结构。接口用途/容量不兼容时先解决，不能伪造字段或绕过；已有板复用与历史任务恢复分别记录 |
| 叙事目的、视角与信息 | 视频目的、核心事件、人物目标与阻力；观众跟随谁，何时知道/误解/发现什么；每场新增信息 | 事件与结果明确；信息披露顺序有因果；镜头有叙事职责；终局及必要反应有时长，不能只写高潮无结果 |
| 情绪曲线、密度与留白 | 紧张/释放、铺垫/兑现及关系变化；动作和对白容量；空镜、沉默、停顿的用途 | 正常速度能演完并听清；留白有意图；开场抓手按用途决定，短视频传播目标才考虑前几秒抓手，不强制所有电影前三秒爆点 |
| 人物表演、潜台词与对白 | 刺激→情感/意图变化→具体表情与肢体反应→残留；人物想得到或隐瞒什么；说话者与倾听者各自的表现 | 表情丰富、情绪有层次且当前景别可见，肢体表达有变化，不能只贴情绪标签或反复微笑/点头/站姿；强弱按剧情，不一律压成小幅微表情；台词原文/归属/语气与气口清楚，武戏发力、吃痛和反冲不削弱；英文提示词保留中文设计细节 |
| 场面调度与物理因果 | 人物、道具、出口/障碍的世界位置；起点、路线、终点；重心、支撑、接触、重量和材质反馈 | 主动作有启动→路径→接触/反馈→恢复；拉开后的距离闭合可见；动作符合角色身体结构；非现实能力仍有一致的作品内因果 |
| 真实接触、碰撞与物质反馈 | 按导演流程核对接触双方/位置/时序、受力或物质转移、对象响应和后续状态；舔饮、抓握、踩踏等与打斗同样适用 | 对象有符合材质/力度/尺度及固定约束的反馈，不能只有主体动；舔奶含实际触液、奶液带起/入口及奶面局部变化，避免静止贴图、隔空转移；无穿模或提前响应，关键接触可见，液量/湿痕/位置等跨镜连续；英文正文与中文方案一致 |
| 摄影动机、镜头与焦点 | 每镜观众要看懂什么、跟随谁、起始机位/景别、路径/速度、焦点、止点和切出触发；随情绪、关系与动作信息主动设计景别/角度/高低/运动及反应镜头变化 | 全片镜头有目的地变化，长期同侧/同景别/同运动须修正或有明确叙事依据；每次移动/变焦/转焦服务信息或情绪；覆盖表情、肢体及发力/接触/反应，不同时要求面部微距与全身全景；不按固定切镜配额或生成段数凑丰富，严格保留原片的任务遵从源片 |
| 光影与环境时间 | 时间、天气、光源来源/方向/色温、软硬、光比、阴影和人物分离；前中后景光层次 | 同场次光照连续且来源合理；重要表演和接触可辨；轮廓光按需要采用；保留有用高光/暗部层次，不机械把硬光等同悬疑 |
| 项目风格继承、色彩与防漂移 | project.yaml.documents.style唯一依据与认可基准；固定材质/光影/色彩及允许变化；近景参考、白模职责和每段英文风格核心 | 以本片风格为准，style与materials引用一致；来源版本/哈希可追溯，每个实际请求都落实且与已审正文一致，近景与后半段未漏约束，无灰模/静态姿态污染或CG表述矛盾；色彩服务剧情，不机械冷暖或滤镜代替风格；源段首中尾/近景/接缝/最终版的网页风格专项仍待真实输出核验 |
| 美术、置景、服化道与材质 | 建筑数量/形制、前中后景、地面纹理尺度、栏杆与地平线；道具叙事用途；面料、旧损、阶层与境遇 | 已选场景有具体空间锚点；材质与反光协调；身份与服装稳定；装饰不抢叙事焦点；留白和空墙可按意图保留，不强制背景堆满 |
| 主体与物体的尺寸 | 体量类比、同场相对比例及握持/承托等大小参照；体高/体长与尾翼计入范围，区别实体大小/距地高度/画面占比 | 按导演流程「主体与物体的尺寸约束」核对已确认大小、参考/白模/英文正文及真实投影；类比不换身份或偷加动作，遮挡/换角度保持实体尺度；未测量不称精确比例通过，当前案例比值不作通用默认 |
| 声音、听觉视点与音乐 | 视频生成默认仅已有对白、无音乐；无对白默认静音；环境声/拟音只按明确要求。后期按完整故事安排配乐与留白、进入/退出事件、强度与对白避让 | 视频英文prompt排除BGM/歌曲/哼唱，不能把后期音乐编译进分段生成；明确保声任务按例外处理。配乐不按生成段重启，记录无音乐区理由、真实音乐入口/缺口及剪辑后cue校准计划；实际对白可懂度与跨镜声音连续留待网页听音，生成前不假报混音通过 |
| 剪辑、视线与节奏 | 眼睛落点如何承接；切点在动作/情绪的哪一拍；轴线、视线、运动方向与景别变化；声音先入/延续 | 切镜新增信息并维持可理解空间；有意越轴有方向依据；关键接触与反应不被切掉；视线跳变需服务意图而非机械禁止 |
| 复杂光学转场与生成段界 | 按multi-segment-video.md记录连续摄影速度链所在单元、可见切镜位置、段内转场启动/完成；预设源端及补帧后检查 | 不把眼缘/遮罩/光学转场标签当作切镜或速度证据；段界不得依赖同景别减速归零再启动；硬切的跨界插值须实查，规则维护不重做已接受旧片 |
| 状态连续性与多段运动 | 身份、左右手、朝向、道具、伤势、衣物湿损、世界位置、破坏痕迹、光照；段尾出态和下一段入态 | 逐邻接核对状态；默认预设计可见切镜/转场，明确连续例外的边界图是经过的相位，段尾仍动、段首接续方向/速度/接触；同图不能代替运动设计；保留因果和终局 |
| 时间稳定性与动态环境 | 遮挡前后身份/道具保持，纹理/建筑/阴影稳定；脚底支撑；风、水、烟、雨持续且相互协调 | 参考职责与稳定性约束清楚；瀑布等不能仅有静态水花；写明实际播放才可判断的项；补帧不能替代缺失动作或物理逻辑 |
| 生成输入、容量与可控性 | 当前模型/入口的实际图像、视频、音频、首尾帧槽位、时长、分辨率；参考各管什么；复杂镜头是否需要预演 | 真实字段与图序一致；无相互冲突的站姿参考或模板句；英文执行稿与中文创作稿一致；多角色/多事件/运镜/特效在时长内可读；不以提示词声明代替能力核实 |
| 默认先白模 | 新视频制作默认先做简单几何白模，合格已有白模复用或用户明确另定流程；复杂光学转场补预演 | 工程/独立检查/完整预览依据真实，摄影与路径/接触/节奏已核对；正式端点和秒数据此复核；预演用于规划还是实际视频输入已区分，不伪造接口字段；纯恢复/文件处理不倒补 |
| 观看场景、后期与交付 | 默认横屏16:9，制作默认24fps、最终交付60fps；手机/大屏的主体可读性；调色、镜间曝光/肤色/锐度统一；混音、字幕需求、编码与版本 | 不考虑平台UI安全区域；保留动作构图余量；真实帧率与处理计划明确；不自动加黑边；先剪辑再自动调用补帧到60fps；保存输入/任务/剪辑版本；生成前只审计划，后续技术结果和用户审片另记 |

新增跨段必检：从剧本和英文正文预设计N−1处可见切镜/转场及视觉/声音承接；速度连续链尽量留在≤15秒同一次生成内。前后各2秒为检查上下文，不能把首尾静帧/短时长当边界速度证据；按multi-segment-video.md审实际接口和原底轨处理。

## 汇总判断

- **可以供用户决定生成**：全部适用的生成前必需项已检查并修正，证据可定位；仅剩已明确呈现的用户选择/接受节点。
- **需修正**：存在矛盾、不可读动作、缺失物理反馈、连续性断裂或确认内容被改动；按导演流程「提示词迭代审计」持续修稿与复核到全部适用标准通过，不以已审轮数或修改建议代替实际修正。未通过稿不得作为最终提示词交付或提交。
- **待核实**：缺实际素材、接口依据或版本信息；列影响镜段和补法，不将待核实项写成通过。
- **后续实测项**：运动稳定性、表演效果、音画同步、最终文件及接缝等尚无输出时，记录检查计划；不伪造完成。

全局复核：是否所有局部决定服务同一故事与风格；所需内容能否在时间和画面内完成；
是否把全部条件写成互相抢占的同一瞬间；是否保留用户已确认内容并遵守当前授权范围。

方法出处：用户2026-11-09提供的五类视听/制作清单及同次对话补充、2026-11-10表情/情感/肢体与镜头表现、真实接触反馈及提示词迭代审计强制要求、项目现有导演规则。
