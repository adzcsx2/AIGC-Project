# 电影级剧本与生成前审计

仅剧本需要说话的人物按 `docs/工作流/character-voice.md` 核查人物ID、声样、用户试听确认与实际音频槽。无台词/非语言声不触发配声。显示名不自动写入台词。未确认声音只使依赖该音色的生成项待定，继续独立工作，末尾集中试听；不得将此待定项标为已完成，也不把音色参考槽当成确定的多角色口型保证。

本技能是剧本创作的前置基准和生成决策前的总审计入口。先读项目 `AGENTS.md` 和
`docs/skill-routing.md`，沿用当前作品与用户确认版本。所有项目路径相对项目根。

## 强制时序

新视频总审计核对已完成的简单白模预演、合格已有白模复用或用户明确例外，按 [默认先做白模](../../../docs/工作流/白模制作与验收.md#默认先做白模) 执行；首尾图不代替运动预演。只写剧本、纯查询/恢复及现有文件处理不启动制作。

**先参考本技能写剧本 → 按需细化动作、运镜、表演和素材方案 → 本技能总审计并修正 →
向用户展示结论并提醒/询问是否生成 → 用户确认后提交。**

- 写、补、改视频剧本或打斗剧情时，不要求用户点名技能；必须先读本技能及
  [电影级检查清单](references/电影级检查清单.md)，然后再进入具体动作或摄影设计。
- 总审计必须在准备向用户说“是否生成”“可以开始生成了”或发出同义提醒之前完成。
  **不能等用户说“确定生成”后才启动总审计。** 用户的生成决定应基于已经审过的方案和结论。
- 审计不通过或尚有必要材料待核对时，先修正或列具体缺口，不把方案标为可生成，不发生成确认提醒。
- 用户确认后只核对当前版本是否仍是已审版本、素材绑定和实时接口参数是否有效；不把此时的技术校验冒充前置总审计。
- 凡规则约定“用户审图后直接生成”的流程，总审计应在向用户交付最终审图/生成决策材料前完成；
  图的接受状态可标待用户确认，不能将未查看、未就绪的图标ready。用户确认同一批图后直接执行既有授权。
- 用户已给出的明确生成授权继续有效，不为审计增加独立的收费确认或重复确认；准备阶段仍须完成审计，
  若改变了需用户决定的剧情、素材或方案，则先展示变更与新的审计结论，按该变更的确认规则处理。

## 默认制作规格

- 用户未特别说明时，采用 **16:9横屏，生成和剪辑默认24fps，最终成片自动补到60fps**。写入需求、分镜及交付计划；
  画面自然铺满画幅，不因“电影级”自动改2.39:1、添加黑边或改竖屏。最终补帧由专用技能在剪辑、拼接和音轨完成后执行。
- **不考虑平台UI安全区域**：不预留点赞栏、头像、平台标题遮挡区，不将其列为审计缺口或阻塞项。
  头脚余量、动作最大展开、兵器路径、视线与行进空间仍属于构图和动作可读性要求，照常检查。
- 用户本次明确指定的比例、帧率、原片保留要求，以及当前作品已有明确确认的规格优先。
  明确调用补帧技能时沿用其专项约定；不因新增默认值重编码旧片或修改历史执行记录。
- 制作默认24fps，最终交付默认60fps；所选API不一定提供fps字段。支持时按制作需求用真实字段设置；不支持时记录原生帧率、
  可行的最终60fps补帧处理及运动伪影风险，在用户决策前披露。不能虚构参数，也不能只改元数据或播放速度冒充达标。
  不能兼顾目标规格与所要求的动作/时长时列具体缺口；后续交付需核对实际文件。
- 帧率、快门式运动模糊、主体速度与摄影机速度共同影响动态观感；不将24fps或高分辨率写成品质保证。

## 写剧本时使用

1. 读取用户目的、已有故事、当前确认、角色/场景和参考职责。固定角色、事件、台词与结果的保留要求。
2. 按检查清单建立适合本作品的创作基准：观众跟随谁、获得什么信息、情绪如何变化，
   人物为什么行动，以及光影、美术、声音、空间和状态如何服务这些变化。
   必须应用根规则及 `docs/工作流/director-workflow.md`「表情、情感与镜头表现」：从剧情阶段设计丰富表情、情感层次、肢体反应和有作用的镜头变化，不能只写抽象情绪或把所有文戏默认写成小幅微表情。
   有接触互动时同时应用该文「真实接触与物质反馈」，写出接触点、对象/液体响应与后续状态；舔饮等日常动作同样不能只有主体运动。
3. 用中文交付剧本或补全稿，写清可见事件、触发与反应、场面变化及必要声音。
   每场至少能回答“观众看懂什么 → 人物如何行动 → 怎样看见/听见 → 留下什么状态”。
   不强制每秒都有台词、特效或切镜；结尾留足结果与反应时间。
4. 再按路由将真实缺口交给动作、摄影、演技等技能，整合回同一版正文；
   文案不足仍先按项目规则让用户确认中文补全稿，不能提前制作依赖它的正式分镜和提示词。
5. 剧本阶段未产生的精确机位、参考图、接口参数应标明后续负责人/阶段，不假称已经就绪。
   用户只要求剧本时交付剧本及必要说明即可，不擅自生图、生成视频或发出强制生成问卷。

## 生成决策前总审计

跨段镜头按multi-segment-video.md的2026-11-11规则：剧本/分镜/实际英文正文逐口预设计可见切镜/转场，连续速度链放同一≤15秒生成内；核对出入画面差异、叙事/状态/声音承接，不能等输出后再靠首尾短桥接猜速度。

在最终方案已可供用户决定时，再完整应用检查清单，不能沿用写剧本时的初步检查代替。

声音审计按 `docs/工作流/music-postproduction.md`：检查新视频仅生成既有对白、英文prompt明确禁音乐、无对白默认静音及明确的原声/音效例外；后期配乐布局必须说明有乐/无乐的叙事理由和进出触发，不按生成段独立起曲。生成前审音乐意图和实际能力，剪辑后的精确cue、混音与听音属于后期实测，不能预填通过。

1. 对照当前需求、剧本、视觉设定、分镜、英文提示词、实际参考素材/顺序、配置和已有专业审计。
   单段或简单任务使用真实现有资料，不为凑文件重建五份文档。
   按导演流程「项目风格与防漂移」核对唯一style入口、认可基准及近景参考、风格来源版本/哈希、每段实际英文正文与请求一致性；检查白模职责及生成后风格专项计划，不能凭文档ready或一句“cinematic”放行。
   体量关键时同时应用 [主体与物体的尺寸约束](../../../docs/工作流/director-workflow.md#主体与物体的尺寸约束)，核对大小参照、比较范围、参考/白模/正文一致，以及实体大小与距地高度/画面占比的区别；未实测比例不预填成片通过。
2. 逐项记录证据位置与具体结论：`通过`、`需修正`、`待核实`、`不适用（理由）`。
   不要求每片都有对白、音乐、打斗、复杂运镜或多段；没有的内容按叙事意图注明不适用。
3. 对照中文创作正文与英文执行稿，检查是否遗漏、冲突、超出时长容量或输入能力；
   表情/情感变化、肢体语言及镜头多样性须有具体正文证据，不能只在说明里承诺丰富。
   持握左右手、朝向、动作启动、关键接触、场景锚点、运动余量和伤势等不得只用风格词代替。
4. 不改变用户已确认内容的执行缺陷直接修正并复核；需改变剧情/身份/结局/已选素材的项明确呈现，
   不替用户改定。修正后重新核对受影响项与全局一致性，不以“已建议”标通过。
   依导演流程「提示词迭代审计」继续改稿与复核，直到所有适用标准通过；不以审过两次结束。缺真实证据或待用户决定项保持待核实/待决定，未通过稿不作为最终提示词交付或提交。
5. 用 [生成前审计模板](../../../templates/short-drama/电影级生成前审计.md) 记录本次结论，
   放入当前作品的 `电影级生成前审计.md` 或现有审计文档；只在已有作品需要留档时写入，不新建竞争生产状态。
   记录剧本及关联输入版本/哈希、问题与修复、实际规格和剩余用户决定。
6. **先展示审计结论，再发生成提醒。** 可在同一条回复中先写通过项、已修问题与实际限制，
   再按当前授权说明下一步或询问是否生成；不得先询问、等确认后再审。
   核心缺口未解决时只说明缺口及补法，不使用“已准备好生成”。

审计后改变剧本、分镜、提示词、关键素材或输入方案，原审计对变更部分失效；
重新核对依赖和全局一致性后，才能再次作为生成决策依据。批量计划各段均在同一总审计范围内，
指定段重做审该段及共享边界影响，不重新编排其他已确认片段。

## 职责与边界

用户要求对已有文案或设计查漏、优化与复核时，可由 [rewview](../rewview/SKILL.md) 按项目路由整合发现及修订；本技能继续提供电影级基准和生成提醒前总审计。复用同版本依据与证据，不相互递归启动；纯文字的局部通过不能冒充完整生成方案已就绪。具体职责以路由表为准。

具体交接以 `docs/skill-routing.md` 为唯一维护表。本技能建立共同基准与检查结果，
专业技能负责具体招式、摄影与表演，`short-drama-workflow`继续持有跨阶段状态，`autodl-aigc`负责真实接口与执行。

- 新提示词仍全英文，说明/剧本/素材名用中文；专项提示词二次审计、文案确认及真实素材绑定继续适用。
- 前置审计通过仅表示方案已审，不表示尚未生成的视频符合要求。
- 保留技术检查、全部接缝验收、用户整体审片及用户新增的风格一致性专项；不增加默认逐段剧情/表演/运镜全项创作审计。
  清单中的时序稳定性、混音和交付项，在生成前检查计划与验收标准，成片未查看时不得标实测通过。
- 纯查接口、任务查询/下载、本地补帧、仅合成已有片段及代码/规则维护，不触发重新写剧本或新视频总审计。
  原片复刻依照源片，只检查适配与实际变更，不能为“电影级”新增原片没有的剧情或运镜。
