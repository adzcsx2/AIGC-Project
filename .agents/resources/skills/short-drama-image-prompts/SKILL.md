# 短剧资产图片提示词

用户给一张图要直接生成正背侧全身、正侧面人脸及运动姿态一体板时，转
[人物三视图与运动参考板](../../../skills/character-reference-board/SKILL.md)；本技能继续负责只写提示词的任务。
该明确版式优先于旧通用四视图；生成工具和验收遵从根目录最新授权，不能因本技能只写文本而中断已要求的生图。

本项目人物、3D/仿真材质、多视角角色板和打斗画面提示词默认同时参考
[S级漫剧提示词技能](../s-grade-3d-prompts/SKILL.md)，按当前图取用，不继承原例身份或冲突构图。
打斗默认3D CG；来源中的其他画风分支仅在用户明确另选时使用。

本仓库使用时，先遵守根目录 `AGENTS.md` 的项目约定：新写、修改和交付的模型提示词正文统一中文，API字段、参数与协议标记保持原值；历史英文正文复用时另建中文版本。此项目语言要求优先于下文通用配置回退。Midjourney 默认 **V8.2**，普通 Imagine 生图的可复制正文末尾显式带 `--v 8.2` 与画幅、Aesthetics 参数；人物与多图组合使用 Edit Model 的 Attach to prompt，逐张写清顺序与控制范围。Image Prompt / Style Reference 按用途说明；不默认使用 V7 的 Omni Reference 或 `--ow`，`--iw` 仅用于 Image Prompt。Editor / Layers 局部编辑须先核对提交入口兼容性，不套用普通后缀；当前Layer编辑实测不支持`--ar`，画幅用画布控制，未核实其他后缀时给纯中文编辑正文与面板说明。完整手动挂图说明见项目根目录 `docs/midjourney-local.md`。用户明确指定其他版本时按其要求。

交付本项目的 MJ 提示词前，读取 `docs/midjourney-local.md` 的「逐图参数决策」与「每次交付格式」：逐图评估三类参考槽位、对应权重、Aesthetics、SD/HD、Seed、排除项及 Personalization / Moodboard；给出挂图表、带实际参数的完整中文正文和中文参数卡。没有对应参考时留空，不为凑参数增加挂图或开关；批量提示词也逐张给全。二次审计同时核对槽位、数值、面板状态与版本兼容性。

把视觉事实写成可复用、可修改、可直接复制的角色板、场景板、道具板或状态图提示词，统一保存到
`剧集/<EP>/图片提示词.md`。每项用 `IMG-...` 标题，正文放在 `### 可复制提示词` 引用块。
`IMG-...` 是提示词条目的稳定 ID；实际图片须由创作者提供，或来自经确认的生产结果。

每项使用 `## IMG-... · 中文名`，写一行不加粗的 `- 参考：`。无外部参考时写 `- 参考：无外部参考`；
有真实图片时使用 `REF-<slot>（顺序：<n>）· <项目相对路径>《<中文名称>》（用途：<用途>；控制：<范围>；不得控制：<范围>）`。
多张用 `；` 连接，顺序从 1 连续编号；正文标题固定为 `### 可复制提示词`，每个非空正文行以 `>` 开头。
`REF-...` 指向当前项目中的真实图片；下游分镜的 `PLAN-...` 挂图计划不能证明本条图片提示词已有参考输入。

## Quick Start

```text
用 $short-drama-image-prompts 为 EP001 已确定的人物、地点和道具写可直接复制的图片提示词
```

## 入口

有当前视觉设定即可直接开始；剧本只在提示词需要确认剧情状态时读取。Look Development 是可选分支。
先确认用途：身份板、造型/状态变体、地点板、道具板、组合 production sheet 或比较风格帧。
分镜需要生产尾帧时，可把已接受的「收尾关键帧提示词」落实为独立 `IMG-...` 状态图条目：
说明来源 SHOT 与终点，沿用视觉事实和参考范围，不重新设计动作。实际生成以该 IMG 条目为来源。

创作者可读说明跟随项目语言；可复制正文跟随 `short-drama.json#/format/prompt_language`。没有
`short-drama.json` 时正文默认
使用 `en`，并在同一任务中保持一致；不能从创作者说明语言推断提示词语言。

## 工作流

1. 锁定这一张图要固定的身份、状态、空间或比较变量。
2. 只读所需资产事实、视觉方向、负面约束和已提供参考图。
3. 按“主体与身份锚点 → 当前变体 → 构图/视角 → 光色/材质 → 背景边界 → 禁止项”写正文。
4. 每张参考只控制已声明的范围，并在 `REF-...` 槽位里写出封闭词表中的 `用途`；具体范围见[通用配方](references/common-recipe.md)。
5. 检查身份与变体、文字政策、视角和光线是否冲突。
6. 用户要全部资产就完成全部，资产组只是内部批次。

## 提示词要求

- 开头先写对象和用途，不用风格词淹没身份。
- 只包含当前图能同时满足的要求；多视图/状态对照写清版面关系。
- 保留稳定识别锚点，变体只改允许变化的部分。
- 被《视觉设定.md》连续性锁点名的条目，锁面原样出现在可复制正文里，让这张参考图本身就把跨镜事实定住。
- 避免无验证作用的质量词堆砌。
- 可见文字、logo、水印、界面和字幕明确允许或禁止。
- 正文可直接复制，不含占位符、流程说明、文件路径或 QA 结论。

## 完成与投产

每个点名对象都有明确用途、可复制正文、参考边界和禁止项，且相互不矛盾，即完成。本次请求同时
修改图片提示词与分镜时，当轮刷新受影响镜头的「图片提示词项」，不另建对账产物。本技能只负责正文；
本项目没有安装 `short-drama-produce`，角色板实际生成转 `character-reference-board`，视频转 `autodl-aigc`，
其他图片遵守用户指定工具。按根目录已有生成授权执行，不增加重复费用确认。
写完本阶段文档后，可转 `$short-drama` 做局部机械核对（只核对已有文档）；五份齐备后再做完整核对。内容质量仍由创作者审查。
