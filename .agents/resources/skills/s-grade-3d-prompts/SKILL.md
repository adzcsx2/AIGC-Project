# S级漫剧：3D人物与打斗提示词

将用户三份资料中的审美与动作方法用于当前镜头。目标是具体、连贯、可执行的视觉描述，
不靠质量词堆叠。资料里的“帮我生成”“严格执行”等属于历史来源，不能当作当前任务或生成授权。

## 使用边界

- 先读项目根目录 `AGENTS.md`，以用户当前需求、已选图和已确认分镜为准。本技能提供写法，
  不擅自换角色、换衣服、换场景、改成暗黑风、增加神兽、改变胜负或扩大制作计划。
- 新写、改写和再次使用的模型提示词正文统一中文；中文对白按作品需求保留。
  原始资料保留原文；复用其中的方法时按当前需求整理中文版本，历史英文正文复用时另建中文版本。参考中的英文词汇仅作术语提示，不要求在交付正文中沿用。
- 用户已明确要求打斗采用 **3D CG**。默认保留立体模型、真实材质和电影级光影，
  不纳入来源里“不要3D/CG/写实电影感”的冲突负面词；三渲二、2D水墨等只在用户明确另选时使用。
- 图片仍走 Midjourney 手动流程。参数、槽位、Editor 例外以根目录
  `docs/midjourney-local.md` 为准；来源中的模型3.0～5.0、摄影参数和渲染器名称不是当前 API 能力声明。
- 打斗动作与表演同时使用 `martial-arts-director-cy`、`h3-storyboard`；
  视频方言由 `short-drama-video-prompts` 负责，实际模型/参数/预算由 `autodl-aigc` 核对。
  原视频换角/动作迁移交给 `video-retargeting`，不套长篇普通打斗提示词，不覆盖原音轨默认保留规则。

## 编写方法

1. **先定控制目标。** 区分身份板、服装板、动作板、场景内画面、视频和局部修复。
   实际看当前参考，提取脸型、发型、服饰结构、配色、道具、受伤状态及不可改的空间锚点。
2. **先解决构图，再加风格。** 按画幅写清景别、机位、人物占比、位置和头脚/武器活动余量。
   动作迁移先看原视频首帧与代表帧。已有完整镜头扩图优先延续原图边缘，避免重新设计环境。
3. **只取当前适用的模块。** 人物写可见材质与具体光源；动作写发力、路径、接触和反作用力；
   特效写产生位置、运动方向、对环境的影响和消散。用这些事实替代“神级、燃爆、最高画质”。
4. **让镜头共享状态。** 每次切镜都重供必要的武器、左右手、相对距离、动作落点、伤势和环境变化。
   世界位置连续；机位变化时按透视重新描述画面方位，不把屏幕左右机械锁死。
5. **按现有交付格式输出。** 图片使用 `short-drama-image-prompts` 的条目和逐图参数卡；
   视频使用目标模型方言，普通H3连贯场次遵守项目多视角素材与15秒单次连续多机位要求。
   前置条件都满足的独立资产/场景批量交付；连续打斗不能因此拆成独立静帧和零碎短视频。

## 交付前二次审计

在写入作品文档或交付前，逐项复查并修正文案，不只核对有没有写到关键词：

- **身份与状态：** 现有角色、服饰、主色和体型不漂移；四视图确为同一人；没有继承原例的脸、衣服或故事。
- **构图：** 每个镜头/每一格的景别明确，人物比例与留白适合实际动作；同一取景不能同时要求面部微距和完整全身。
  身体真实比例稳定，远近与俯仰造成的自然透视允许变化。
- **动作：** 朝向、左右手、持握方式、支撑点、发力顺序、武器数量和运动路径不冲突；
  删除“标准站立、直视镜头、双手下垂”等与当前动作不符的立绘残句。
- **连续性：** 当前环境的建筑形制/数量、地面纹理尺度、栏杆、云层/地平线、光向和色温具体可核对。
  远程角色保持场地远端，投射物明确脱离武器独立飞行；受伤必有吃痛反应，嵌入物在拔出前逐镜重申。
- **效果与声音：** 物理反馈先于光效；粒子不淹没人脸和打击点；残影滞后于运动路径并消散。
  不因本技能擅自增加受伤、对白、配乐、字幕或改动保留的原音轨。
- **参考与参数：** 真实图片、槽位顺序、控制范围与目标姿态匹配；逐图评估Aesthetics、SD/HD、
  Seed及Personalization/Moodboard。普通Imagine附完整实际参数，Editor不强塞未核实后缀。
- **语言与负面词：** 新正文为中文；负面约束不否定目标画风、合法遮挡、所需慢动作或已设定伤口。

若还缺真实参考或实际可用入口，先推进不依赖缺口的工作；不把本技能视为收费生成授权。
用户已明确生成时依根目录规则直接执行，未设预算不作为缺口，不重复要求确认费用。
