# 多视角角色板

用户2026-11-08最新指定：一张角色图扩为**正面、背面、侧面全身＋正侧面人脸**，
有运动用途时将真实爬行/飞行等姿态加入同一灰底板。执行与验收以
[人物三视图与运动板](../../../../skills/character-reference-board/SKILL.md) 为准。
下列旧版式是可选历史配方，不再将正背俯仰四格强套给该需求；已有合格板无需仅为新模板重做。

来源：TXT的“左脸部特写 + 右正侧背全身”排版与一致性约束；
项目的动作多视角要求决定生产板应采用的高低机位。先区分两种板，不能都简称“四视图”后混用。

## 选择版式

| 用途 | 同一张16:9图的内容 | 说明 |
|---|---|---|
| 人物身份、妆发和服装细节检查 | 左侧较大正面脸部特写；右侧正面、严格90°侧面、背面全身 | 来源TXT的身份服装板；约40%左区只是排版起点，不替代动作板 |
| 连续打斗或连续场次的视频参考 | 正面全身、背面全身、俯视图、仰视图，四格或并排 | 遵守项目要求；不能用左脸+正侧背冒充已有俯仰透视 |
| 已确认连续动作的空间规划 | 一张多宫格连续动作分镜母板 | 各格共享同一角色、场景、光向和状态；不得拆成多张互不相关的静态图锁死短视频 |

角色基础外观确认后才锁多视角。已有身份板时复用其身份信息，补足动作所需视角；
不擅自多出另一套角色或把用户没确认的候选当定稿。

## 同一人、同一套服装

- 明确所有视图属于同一角色，锁脸型、五官、瞳色、肤色、妆容、发色/长度/束发结构。
- 锁服装正背结构、颜色分区、层次顺序、刺绣位置、扣带、鞋袜及饰件数量。
  服装的后腰蝴蝶结、披风开合、武器挂点等是背面锚点，不能凭视角重新设计。
- 正背板保留原设计的完整身体末端与双手；人形有脚鞋则展示，蛇妖展示连续蛇身与尾尖，不添腿鞋。普通人形身份板的正侧背高度与脚底基线一致。
  俯仰图允许符合透视的视觉缩短，不能同时强求与平视图完全相同的屏幕高度或脚线。
- 普通角色保持同一真实身高和骨架比例；不把原TXT的九头身、小头或60%腿长套给所有人物。
- 角色设定板各格用可读细节的景深、统一柔光、相近曝光和简洁背景；连续场景分镜母板则保留已选场景、
  真实光向和空间层次，不能换成影棚。俯仰板需要清楚的视角变化，
  不能只给同一平视立绘换个裁切。

以下英文模块仅作历史表达参考，实际交付时按当前需求整理为中文：

| 目标 | 可重组片段 |
|---|---|
| 同一角色 | `the same character in every panel, with consistent facial features and costume construction` |
| 身份服装版式 | `a large frontal facial close-up on the left; front, strict side-profile and rear full-body views on the right` |
| 动作视角版式 | `four panels showing a frontal full-body view, a rear full-body view, a high-angle top-down view and a low-angle upward view` |
| 细节可读 | `all essential costume details remain in focus, with clear separation between panels` |

这些是版式模块，不是带模型参数的最终提示词。按当前用途选一套，交付时去掉未选版式和占位说明。
不要求在图内渲染“正面/背面”、数字、箭头或网格标签，除非用户确实需要可见文字。

## 挂图与运动留白

- 实际查看已选角色图后，按项目规则决定身份图放Attach to prompt、风格图是否需要Style Reference；
  没有场景用途就不给角色板机械挂场景。明确每图控制身份、衣装、风格或空间的哪一部分。
- 每图按 `docs/midjourney-local.md` 独立给槽位顺序、完整中文正文、最终参数、中文参数卡和中文保存名。
  示例保存名可为 `角色-银发法师-动作四视角设定板.png`，不能把示例当现存素材。
- 多视角板负责外观和视角依据，实际动作首帧仍需足够的头脚、侧向和武器活动余量。
  结合原片/目标动作测定占比；不把云宫挥杆的72–75%高度、横向40%推广到所有镜头。
- 成图后逐格检查身份、背面结构、持握左右手、视角是否真实成立；看图通过且用户选定才登记ready。
  返回图的实际占比与留白须重新检查，不能用提示词写了某个百分比代替验收。
