## 已做的适配与冲突处理

| 来源写法 | 本项目采用方式 |
|---|---|
| “严格输出中文”“即梦Dreamina” | 取创作方法；新正文中文，图片仍Midjourney手动，视频沿当前模型 |
| 模型3.0、4.0、4.1、4.6、5.0 | 来源标签，不能当MJ版本、工作流ID或API参数 |
| 8K/32K/888K、多个渲染器名 | 视觉意图；真实分辨率与能力查目标模型，不作执行保证 |
| 人脸微距、半身、全身、航拍/仰拍混列 | 按当前图选唯一可执行景别与机位，删冲突残句 |
| 左脸+正侧背“四视图” | 身份服装板；连续动作另按项目正背+俯仰四合一或连续分镜母板 |
| 85mm、f/2.0浅景深 | 人像可选意图；多视图需细节可读，不机械浅景深 |
| 体型比例锁定、每镜永远同屏幕位置 | 锁世界身高/相对位置，允许真实透视和有交代的机位变化 |
| 每秒固定攻击数、切镜数、固定关节角与微秒级残影 | 密度/效果参考，按动作可读性和模型能力取舍，不承诺精确实现 |
| 所有战斗立即开打 vs 强者8～12秒出场 | 先明确叙事重点；长登场段减少动作，15秒不能容纳互斥密度 |
| 所有技能慢凝聚 vs “不要慢动作/不要蓄力” | 大技能适量形成，小动作简洁；负面词随当前动作裁剪 |
| 全程高密度残影 vs 后文节制原则 | 优先后文路径滞后、分离、渐隐写法，仅最快段使用 |
| “不要3D、不要CG、不要真人、不要写实电影感” | 原文P0866的局部风格负面词，不用于当前3D/仿真目标 |
| 2D水墨、三渲二等画风分支 | 用户本次已明确打斗采用3D CG；其他分支仅在明确另选时使用 |
| 神兽一律暗黑、至少六个锁词 | 只在用户已选暗黑方向取合适材质；不计数堆词、不覆盖现有审美 |
| 双方1秒内重新近身 | 仅近战可参考；弓手/法师保留远程空间和独立飞行投射物 |
| 命中次数机械对应轻伤到终结 | 按已确认剧情受伤并保留；真实吃痛与嵌入物逐镜连续遵守项目强制规则 |
| 无文字 vs 六字真言/符文/方向箭头 | 无字成片用抽象非字符纹样与文字方向描述；不把策划箭头生进画面 |
| 无抖动跟拍 vs 镜头震动 | 跟拍路径稳定，命中才有短暂相称的冲击，不全程无焦点抖动 |
| 技能凝聚禁ACT vs 示例ACT下凝聚凤凰 | 凝聚优先稳定电影视角，示例冲突不作为规范 |
| 地面/建筑每次命中必须大规模毁坏 | 物理反馈与设定强度相称，记录变化，不擅自改毁已选环境 |
| 固定原例脸型、银发、九头身、服装与角色名 | 只在当前人物确实匹配时保留，不把风格参照当新身份 |

“S级”是用户资料的名称与审美目标，不是生成结果的质量认证。
