# 中文提示词写法

先读取实际图片并提取具体身份，下面是模块，不能原样连占位符发送。正文、保存文档与工具输入一致。参数属于实际工具，不在通用正文写MJ参数。

## 通用主体与版式模块

> 以附图唯一角色为身份和服装依据，制作同一角色的一张多视角与运动参考板。保留【已观察的脸型、五官、发型与发饰、服装层次与主色、材质、身体比例及识别痕迹】，画风沿用附图。未见背面依据现有结构保守补齐，不新增角色或装饰。
>
> 中性灰背景、柔和清楚的光照，各格轮廓分离。横向整板，上排依次为正面全身、背面全身、严格90度侧面全身；下排为正面人脸近景、同侧严格90度人脸近景和较宽的【实际运动姿态】格。侧面展示角色左侧，鼻尖朝画面左；不对称痕迹固定在原来的身体侧。每个身体格完整呈现头部、手臂、躯干及原设计身体末端，四周有少量余量；脸部格重点看清五官与轮廓。各格都是同一角色的不同视图，不出现拼合肢体、跨格尾巴、独立分身或运动残影。无文字、水印和视图标签。

如果原角色不具人脸（封闭机甲头盔等），正侧面脸部格展示原有头部/面甲，不能捏造头盔内部真人脸。人脸全被遮挡但用户要求露真脸且没有参考时，说明缺少依据；不谎称锁定了看不见的脸。

## 蛇妖运动模块

> 各身体格保持同一位蛇妖的身体结构：一颗人类女性头、一个上身、两条手臂，腰部连续连接一条粗腹逐渐收细的蛇身，末端只有一个闭合尾尖，没有分叉、额外蛇头或人类腿脚。尾部纹理与腹鳞前后连续，衣摆不遮住关键连接。常态格上身抬起由蛇腹承重；运动格用侧前机位表现低姿贴地蛇行，上身俯低向前，手臂自然屈伸辅助支撑，腰到腹部连续，宽腹鳞与灰色地面接触，唯一尾巴在身后以可追踪的平缓曲线延伸，尾尖完整可见。不是站姿平移，也不是人类跑步。

与真实原图结合时保留它的发饰、服装和鳞片配色，不从本次青衣蛇妖照搬身份。灰底可有柔和接触阴影，不加入瀑布、湖岸或柱子。

## 机甲飞行模块

> 保持附图机甲的头部、装甲分区、关节结构及原有肢体数量，推进部件只使用附图与已确认设定中存在的结构。飞行格展示【已指定的悬停或前进飞行】瞬间，身体【对应俯仰】，双臂和双腿【对应收放】，整体明确离开灰色地面，翼面/喷口连接及朝向清楚。少量推进效果只辅助表明方向，不遮挡躯体，不凭空增加翅膀、尾巴、喷口或武器。其余身份格保持相同部件和材质。

若原设计是无腿飞行器就保留无腿；若是有腿机甲就保留腿。由当前角色判断，不能用蛇妖规则删除所有飞行角色的下半身。

## 编辑失败格时

描述确切区域与错误，如“右下运动格出现两条独立尾巴”，再写目标连接关系；锁定其他已合格格的脸、发饰、服装、光照和排列。保留原身份参考，避免让缺陷板成为唯一设计依据。每次修改后全板复查，防止修尾时换脸。

## 交给视频时的角色板说明

> 这张参考板的全部视图都定义同一位角色，仅用于面容、造型、身体结构和目标运动形态；成片只出现一位该角色，不生成灰色背景、拼图边框或多个人物。实际动作顺序、路径、速度、接触和镜头按已审计的动作视频，场景与光影按独立场景参考。

该句需要按真实图序绑定，不给不支持prompt的接口新增字段。设定板不作为固定首帧或尾帧，除非用户选择的实际入口就是首尾帧生成且另有适合的单镜头画面。
