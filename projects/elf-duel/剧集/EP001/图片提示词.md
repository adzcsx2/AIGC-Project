# 图片提示词 · 第一批提案

以下为角色图片提示词。用户最新要求：本轮先用 MJ 生成法师1定妆图；女弓手不同脸、血红衣服、
同一整体画风。每轮成图须先展示并取得用户确认，再执行下一项；其他新增设计仍待选择。
先做IMG-A-FULL、IMG-B-FACE、IMG-LOC，再用选定的弓手脸做IMG-B-FULL。
共享风格参考图为项目根目录 `assets/双精灵对决/参考图-银发精灵.png`；生成时用户在 Midjourney 上传该图。

## 在 Midjourney 里怎样挂图

- 做两人和场景时，将原人像用于 Style Reference，控制色彩、媒介、材质和光线，不用它复制两个人的脸。
- 要沿用持杖者的脸时，另外把原图作为身份参考。V8.1/V8.2 可使用 Edit Model 的 Attach to prompt；
  V7 使用 Omni Reference，不能把不同版本的参数混用。
- 生成弓手脸后先选一张；弓手全身始终沿用选定脸作为身份参考。不要把两次独立随机生成当成同一个人。
- 基础全身与场景按9:16，弓手脸按3:4。先选正确造型再取高清单张；HD设置与所选版本相容时再开。
- 原提示词的 profile 代码是个性化配置，未在用户账号验证；可在实际能加载时试用。
  下列正文先不依赖这些代码，也不承诺仅靠文字重现原图。chaos 0 是资产阶段的建议，不保证身份锁定。

## 第一批选图标准

全身图同时看脸、双手、脚、整把武器；不能只因为脸漂亮就接受截脚或缺半截弓/杖。
两位人物需要各自可识别，不能只换发色却成为同一张脸。
全身图内武器已经清楚时不强制另出道具板；结构看不清或后续有特写时再补。
先选定基础素材，再根据分镜编写双人对峙、出箭、挡箭/反击的单张关键帧提示词。
